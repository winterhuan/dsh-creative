## 当前状态

先用 `scripts/tracking_commit.py check --project {项目根}` 取得 `last_committed_chapter` 与 `state_revision`，不将完整 state 塞入正文 prompt。续写状态卡固定七栏，最多 12288 字节；优先读取它、本章细纲、当前剧情单元和上一章正文。

本章涉及而状态卡缺失的信息，按角色名读一个动态快照、按伏笔 ID 检索当前行、按需要选择作者真相或读者已知视图。只有追溯原因时查相关逐章记录或原文章节。静态人设不能替代当前动态状态，未来揭示计划不能替代已发生事实。

新书尚无正文且无 state，可按 [追踪事务](tracking-transaction.md) 初始化第 0 章。已有正文但无 state，进入 `story` 的已有文本接入流程建立续写状态；无需先完成全书深度分析。state 或派生视图损坏时按事务协议修复，不手写视图或删 state 重来。

## 对标与文风

原创项目可以没有对标：情绪、节奏和风格从本书细纲、卷纲与设定确定，不虚构外部召回。对标是可选创作资料，不是所有小说的运行依赖。

使用外部对标时先读取本书 `设定/题材定位.md` 的明确登记，排除同名或来源指向本书正文的候选。路径优先 `{项目}/对标/{书名}/`，其次 `拆文库/{书名}/`；第一次引用只复制本任务需要的分析子集。多个候选且未指定主对标时说明选择，不能静默换成别的作品。

登记的作品在两处都找不到时，报告实际查找路径并停止依赖它的查询，不改用其他书。书目录存在但缺 `文风.md` 时只报告缺文风，不把整个作品判为不存在。

| 资料 | 权威范围与缺失处理 |
|---|---|
| `剧情/情绪模块.md` | 对标读者需求、情绪引擎与可复用模块 |
| `剧情/节奏.md` | 对标信息推进、情绪触动、爆发与冷却 |
| `文风.md` | 对标句长、语气、对话和原文锚点，不能覆盖情绪/节奏意图 |
| `章节/第K章_摘要.md`、深度拆解 | 具体章节证据；同章深拆不存在可用已有文风技巧，不编造已读证据 |
| `拆文报告.md`、`剧情/故事线.md` | 概览或索引，不能冒充缺失的权威模块 |

本次明确依赖对标模块而 `情绪模块.md` / `节奏.md` 缺失时，定位缺口并用 `story-analyze` 补相关阶段，完成前停止依赖它的准备；不以摘要假装已召回。与用户明确选择无对标创作是两种情况。已有 `设定/文风.md` 的有效约束时以它为准；未指定自定义文风而本次明确要求对标文风时，缺失文件需补分析。生成记录标明不可用、只有标题或占位符的文风文件不算有效。

按本章问题选一个情绪模块、一条节奏参考及相关锚点；保留真实来源、缺口与冲突，不能在总结中抹掉。题材卡按 [索引](../../agent-references/genre-prose-cards.md) 只取相关单卡，缺卡可根据本书材料生成简要取舍，说明置信度；多对标按 [召回预算](cross-book-recall.md) 处理。不要每章整库阅读。
