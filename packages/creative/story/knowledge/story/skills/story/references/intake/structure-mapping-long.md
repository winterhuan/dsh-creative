# 复用已有长篇分析

仅在用户已有分析结果且需要整理工程资料时使用；接入原文无需生成这些分析。按当前任务选择映射，不强制补全整本设定、卷纲或历史章节细纲。

| 已有材料 | 可写入位置 | 保留条件 |
|---|---|---|
| 原文及章节边界 | `正文/第N章_章名.md` | 保留全部正文、标题和顺序；不确定的章节边界先核对 |
| 角色及关系分析 | `设定/角色/`、`设定/关系.md` | 只记有来源的事实，冲突和推测分开 |
| 世界观与势力分析 | `设定/世界观/`、`设定/势力/` | 只创建有内容且当前需要的文件 |
| 故事线和剧情单元 | `大纲/大纲.md`、相关卷纲 | 已发生剧情与后续计划分开；分析不自动变成作者确认的计划 |
| 相关章节摘要 | 待续写章的上下文材料 | 正式细纲按当前 `story-write` 模板补齐；不为历史已写章伪造细纲 |
| 节奏和情绪分析 | `设定/题材定位.md` 的本书基线 | 无材料时留作待研究项，不阻塞正文整理 |

源文有明确分卷时保留；分析建议的卷划分只标为建议，不能覆盖作者划分。拆分正文后核对章号、源范围和总内容，不能用概述替代章节原文。

当前角色状态按 [角色状态反推](character-state-reverse.md) 从相关原文确认。追踪按 [初始化指引](../project/initialization.md) 建立；后续章节事实由 `story-write` 提交，Markdown 视图不能手改。初始化截止章是最后完整章，不是分析覆盖章。

用户自有作品的基线留在本书。只有用户明确选定独立外部参考书，才在 `设定/题材定位.md` 登记 `拆文库/<对标书名>/` 并直接阅读；不能把本书正文或设定登记成对标，也不再复制进 `对标/`。对标缺项不影响无对标原创流程。
