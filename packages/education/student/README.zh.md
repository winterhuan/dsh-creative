# @winterhuan/dsh-student

[English](README.md) | 中文

## 概述

从“学习工作台”侧栏或 `/study` 引导小学生进行简短的语文、数学和英语学习。跨对话保留实际作答、复述、错题复习和虚拟星星。家长确认课程与时长，首份教学参考面向上海二年级上册。此包独立安装，使用 DSH 对话与图片，提供二年级上册语文、数学默认教材课页。

<a id="use-this-package"></a>
## 使用此包

在新建或空白会话的原生模式菜单中选择**智能学习**，再从右侧栏打开对应工作台。工作台及领域技能、工具只在该模式中可用。已有会话保留原模式；要继续已有项目文件，请在该模式中新建会话。会话状态和项目文件不迁移。全局设置仍可使用。

将已构建的包安装到 DSH `0.2.1-alpha.1` 配置，打开独立的学习工作区并调用 `/study`。

```sh
dsh plugin --profile student add /Users/winter/dsh-creative/packages/education/student
```

配置需要已提供技能、工具、会话文件系统和沙箱策略。web 配置还提供对话、图片附件和学习工作台侧栏。安装层添加 `student` Host 行和 `preset-student` 模式行，不安装任何创作包。安装或重新构建后重启配置。

### 使用学习工作台

在学习工作区的新对话中选择智能学习模式，从右侧栏选择“学习工作台”。家长设置创建档案，今日学习开始一个学习段，每次展示一道已保存的题目。在面板提交回答或请求提示，DSH 对话负责教学与评估。操作随题目状态显示为出题、重新请求反馈或提示、下一题，均沿用当前学习段。收到反馈后仍保留原回答。提交成功不等于模型已回复，模型错误仍显示在对话中。

错题巩固将选择的 PNG、JPEG 或 WebP 图片（最多 8 MiB）通过 DSH 原生附件发送，再列出待确认转录和到期复习。成长记录展示星星和近期作答证据。家长设置保存时长、已核对的教材版次及学校进度。刷新会重新载入表单，遇到冲突后先复制未保存编辑再刷新。列表最多展示 20 条近期或待处理记录，完整历史可在对话中查询。

### 选择学习方式

智能学习是会话模式。在学习工作台中选择科目和以下四种学习方式，它们共用每日时长。工作台保存题目与回答，对话承担讲解、提示和辅导反馈。

| 学习方式 | 适合什么时候使用 | 前提 |
|---|---|---|
| 通用基础 | 围绕基础概念或默认教材练习，说明内容来源 | 家长已确认学习档案 |
| 校内同步 | 按已确认的教材和学校当前单元练习 | 已确认所选科目的教材版次与学校进度 |
| 到期错题 | 回忆已确认的错题，或尝试相关变式 | 所选科目有已确认且到期的错题 |
| 自主探究 | 围绕孩子的问题，进行猜想、观察和解释 | 已有学习档案；在对话中说明想探究的问题 |

首次使用先完成家长设置。今日学习显示每日剩余时长、今日星数和到期复习数量。在错题巩固中选择到期科目，会带入对应复习方式，再由用户在今日学习明确开始；活动学习段、休息或每日时长耗尽时不能另开复习。在今日学习中选择科目与方式、开始学习段，尝试一道已保存的题目，需要时请求提示，提交回答后等待反馈。“结束并休息”结束本段，收获复述可以留空。错题巩固负责照片录入与核对，成长记录展示实际作答和学习证据。仅录入照片不会开始学习段。

### 确认学生与资料

每个工作区通过 `.study/state.json` 保存一名学生的一学期。家长确认昵称、地区、年级、学期、学年、五四或六三学制、时长限制，课程备注可选。其他学生或学期使用新的工作区。学年下拉提供当前学年、此前五个学年与下一学年，默认留空，由家长选择。例如 2026–2027 跨两个自然年。课程备注是家庭自定的标签，不是学校官方代码；可以留空。旧档案仍可读取。

逐科确认书名、出版社、版次、封面或版权页依据以及当前单元。校内同步要求版次已识别、课程范围匹配并记录家长确认。课程未确认时可进行明确标注的基础练习。教材改版使用独立资料 ID，先前作答保留原资料引用。官方入口和来源规则见[教材资料](knowledge/skills/study/references/materials.md)。

<a id="use-default-textbooks"></a>
### 使用默认教材

二年级上册未提供某科教材时，`/study` 使用随包提供的人教社语文或北师大版数学，用户提供的教材和课页优先。无需再次上传这两本书；完成档案设置后选择“通用基础”，或在对话中说“用默认数学教材学习乘法”。尚未指定学习主题时从第一单元提供短小选择。默认教材不代表学校采用版本，也不自动填写校内进度；英语和其他年级、学期没有默认教材。

教材目录、版本依据和读取规则见[默认教材](knowledge/skills/study/references/default-textbooks.md)。课页通过 DSH 的 `read_image` 按需读取，需要支持图片的模型；文字层仅供检索定位，不能直接用于拼音、图形或竖式判分。缺少图片能力时使用用户提供或已核对的题干，或明确标注的自编基础练习。

### 学习、休息与复习

辅导者开启一个计时学习段，提出简短问题，等待学生并记录真实回答与帮助程度。二年级建议学习 10 分钟、休息 5 分钟、每天 20 分钟。这是产品建议，不是医学建议；家长可确认的范围分别为 5–15、5–15 和 10–30 分钟。语文、数学、英语、复习和探究共用每日上限。

面板显示学习和休息倒计时，到时禁用作答；关闭面板不暂停计时。时长使用包含等待的钟表时间，以本段截止时间封顶。停止操作记录休息起点，已超时的学习段也需停止；休息结束前拒绝新开学习段。提前停止不受惩罚，也无需补足时长。日期使用上海时区，学习段在午夜截止。不安装后台闹钟或屏幕锁。

每天实际作答最多获得一颗参与星，学生复述可再得一颗。挂机、多刷题、延长学习和连续天数均不额外加星。进度报告展示证据和主题，不排名，也不当作考试成绩。

图片错题由辅导者通过 DSH 读取，保存转录和疑点，再请用户确认修正后的题干与答案依据。所有新错题确认前都处于待核对状态。首次复习在一天后到期，独立答对依次延长到 3、7、14、30 天；依赖帮助或答错恢复为一天。不同三天的独立答对仅作为进展证据，不等于永久掌握。

可以请 `/study` 查看进度、继续到期错题或探究孩子的问题。探究采用小型预测、观察和解释过程，也受同一时长限制。可选的每日提醒仅在家长指定时间后使用 DSH 当前可用的提醒工具，本包不自动创建提醒。

## 理解实现

职责与信任边界见[学生学习子系统](../../../docs/subsystems/student.zh.md)。在仓库根目录通过 `pnpm --filter @winterhuan/dsh-student build` 构建，通过 `pnpm --filter @winterhuan/dsh-student test` 测试。

Host 入口负责工作区路由和配置。`./agent` 导出在 `student` preset 及继承它的原生子 Agent 组合内注册领域技能和工具。preset 提供任务专属 persona 和显式原生工具组合，不改变默认模式。 学习模式使用文件、搜索、网页、提问和呈现工具，不默认挂载 shell、委派或创作生产工作流。

<details>
<summary>实现细节——点击展开</summary>

[配置补丁](cordis.patch.yml)加载[宿主插件](src/index.ts)。[学习状态更新器](src/learning.ts)检查时长、课程、奖励与复习转换，[状态定义](src/schema.ts)校验模型输入和持久化数据。面板和工具共用持久化的题目、已提交答案与提示请求，评分必须对应这些记录。原生工具参数由同一输入定义投影生成。DSH 的常规工具日志记录调用和结果。

[存储层](src/store.ts)通过当前会话文件系统解析 `.study/state.json`，检查工作区包含关系，并在会话沙箱策略下按已观察的文件版本写入。冲突需要重新读取；损坏或不支持的文件不会覆盖。只读操作保留不存在的状态。文件限制为 8 MiB，集合有明确上限，到达后拒绝继续增长而不丢弃历史。进入新学期前备份工作区。相同 ID 的一致重试不重复记账，内容冲突的复用会报错。

[工作区接口](src/route.ts)解析 DSH 主会话，仅接受回环地址及同一来源请求。面板修改必须携带已观察的修订号，不能通过 UI 接口提交评分或奖励。客户端通过原生会话队列提交辅导请求，不替换输入框草稿。

默认教材资源位于技能的 `textbooks/`，随 `knowledge` 打包。目录、逐页图片和未校对文字由[教材准备脚本](scripts/prepare-textbooks.py)从两份已核对的 PDF 生成；脚本使用 PyMuPDF 1.28.2 并在写入前校验源文件哈希。运行时使用原生文件和图片工具，无需 Python、PDF 解析器或原始下载路径。教材选择由技能指引，不自动修改学习状态；默认教材作答的页码和依据保存在 `answerEvidence`。

## 模型体验

### 学习指引与记录

#### 模型看到的内容

所选模式加入领域 persona 与原生工具 schema。稳定 persona 记录在[提示词快照](../../../tests/fixtures/student-persona.txt)中；标准模式和其他领域模式不包含本领域能力。前缀与 schema 在按需加载技能之前占用上下文，原生压缩管理累积历史。 技能目录提供一个 `study` 入口。加载后提供设置、短时辅导、图片确认和探究指引及教学、来源和默认教材参考。`study_status` 读取状态或集合，`study_update` 接收一个有类型的设置、来源、课程、学习段、题目、回答、提示、评估或错题操作。工具描述要求使用真实用户确认和真实学生回答。来源页面与图片是资料，不是指令。

#### Token 影响

技能正文和参考按需加载，启用时提供两个工具定义。状态最多包含 20 条进度和 20 条待核对／到期错题；集合查询每页返回 20 条及下一页偏移。不加载整本教材。尚未测量真实模型的 token 或教学质量基准。

#### KV Cache 影响

插件使用常规 DSH 技能与工具历史，不改写已有消息，也不创建其他模型会话。

## 已知限制与待办

<a id="known-limitations-and-deferred-work"></a>

- 插件不认证家长身份、不测量注意力、不保证 AI 答案，也不提供完整的上海课程库。确认记录用户陈述，来源分类本身不能证明正确。实际教材、学校进度和争议答案仍需人工核对。
- 图片录入依赖支持视觉的 DSH 模型与可读附件。本包没有独立 OCR 服务、教材下载器或自动提醒。图片路径引用提供的附件，不将图片字节复制进状态文件。
- 时长约束限制记录的学习操作，不控制操作系统或任意聊天。超时回答保留在对话中，需在之后的学习段复核。同一工作区使用一个 DSH 宿主写入，不支持多进程编辑或手工修改状态文件。
- 状态保存在本地，但辅导用到的片段和图片会传给配置的模型提供方。插件不是离线或加密的学习资料库。原生工具和文件系统测试不能证明真实模型的识图准确率或教学效果。
