# 教材与答案来源

插件附带二年级上册语文、数学的[默认教材](default-textbooks.md)课页，用户未提供该科教材时按需读取。用户提供的教材优先。校内同步需另行核对实际课本的封面、版权页、目录和学校进度；可使用家长课页或官方资料。仅有网址或书名不能证明模型已经读到正文，也不能据此生成“教材原文”。

## 官方入口

- [国家中小学智慧教育平台](https://basic.smartedu.cn/)：查找官方课程与教材资源。具体教材页面的登录及开放情况以平台为准。
- [人教社中小学教材电子版](https://jc.pep.com.cn/)：核对人教社提供的教材版本；不能由“统编”直接推定所有科目都使用人教版。
- [上海教育出版社](https://www.seph.com.cn/)：官网的“上教教材”列有小学数学、英语等，并提供教材资源平台入口；是否为孩子学校使用的版本仍需核对。
- [教育部义务教育课程方案和课程标准（2022 年版）](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)：核对课程要求，不用课程标准代替学校课本或教学进度。

入口核查日期：2026-10-05。没有据此确认上海某一学校的二年级上册教材版次；也未确认三科教材可下载。不要绕过登录、验证码或付费限制，不使用来历不明的网盘扫描件作为权威依据。

## 第三方教材候选库

[ChinaTextbook](https://github.com/TapXWorld/ChinaTextbook) 可用于查找候选教材。2026-10-06 核对的目录包含小学语文、数学、英语及单独的五四学制目录；五四制数学为青岛版、英语为鲁科版，普通小学的沪教版英语从三年级起，未找到上海二年级对应的数学和英语册。目录名、仓库更新时间与文件名都不能证明当前学校使用该版本。

先按学制、科目、年级、上下册和出版社筛选，再核对选定文件的封面、版权页及目录。仓库里的旧版可以作为概念练习或拓展参考；即使版本较旧，只要与孩子实际课本一致，仍可作为匹配线索。不能把“较旧”直接当成内容错误，也不能把知识点相近当成教材一致。尚未读取正文时，不声称已经解析出课程或原题。

候选资料保留具体文件链接和已核对的版本信息，默认按 reference 登记；未知版次保持 unconfirmed。仅凭第三方仓库文件不得建立校内关联，仍需实物、学校或官方来源核对及家长确认。检索失败或缺少目标版本时，回到官方入口或家长提供的课页，不自动替换为其他出版社、学制或英语起始年级。

仓库中部分 PDF 拆为 `.pdf.1`、`.pdf.2` 等文件；单个分片不是完整教材。按本次学习需要选择具体教材和课页，不整库装入模型上下文。此入口用于查找资料，插件不自动下载或合并教材。

## 建立资料记录

`material` 的 title、publisher、edition 来自已看到的实物或官方资料。scope 保存 region、grade、term、schoolYear 和 schoolSystem（five-four 或 six-three）；年份未知就暂缓校内关联，不猜测。locator 写具体官方页面、教材页码或家长提供的工作区课页路径；evidence 描述核对过的封面、版权页、目录或相关内容。版本不明时 editionStatus 为 unconfirmed，如实写“待核实”；核对后用新的资料 ID 登记 identified 版本，才能调用 `course` 建立校内关联。

kind 区分 official-textbook（出版社或官方平台教材）、school-material（学校发放资料）、reference（词典、科普等参考）和 generated（AI 自编练习）。分类仅说明提供者，不自动证明内容正确。仅在家长确认具体版本与当前单元后调用 `course`；记录实际确认语句，不以搜索摘要或其他地区书单代替。

## 图片、正文和答案

每次只读取本次任务需要的题页。不能清晰识别的单位、负号、标点、拼音和图形条件都要保留疑点。学生原答案与订正答案分开保存；不覆盖学生最初的思路。

answerEvidence 写可复查的页码、词典条目、教师讲解，或完整且复核过的推导。没有答案时可以独立求解，但必须标明推导与资料来源的区别。教师答案、书中答案和模型推导冲突时先核对题干及版本，无法消除的冲突标为待核对，不训练学生接受不确定结论。
