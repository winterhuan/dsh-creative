# 上海小学二年级上册的辅导方法

此文件提供年龄适配方法，不列未经核实的课本目录。具体内容以已确认的学校课本和单元为准，不假定上海所有学校或不同学年使用同一版本。

## 不会做时先教

孩子说不会或看不懂、家长说这题是提示后才做出、本段同一目标错了两次，或提示后仍卡住，就先教方法，再出独立题。摸底段不讲课：摸底题不写 `phase`，只记 `stuck`，讲课留到这段结束。

四步写在当前题的 `phase` 上，和复习卷的换数字、换情境、说理阶梯分开：

1. `demo`：用一道同结构的例子示范。`record` 的 `assistance` 用 `worked-example`。这不是孩子的答案。
2. `guide`：先 `hint`，让孩子做一步。没有提示不能记这一步，也不能标 `independent`。
3. `try`：换数字，孩子独立做。
4. `vary`：先移动括号或改不等号方向，再出两步题。

一次「不会」，或只在提示下做对，就把该目标标成需要教学。这次卡住之后出现一次独立答对，才离开。今日建议停在这个目标上，不排下一课。

前置不够时，用 `start` 的 `scope` 回到更早的目标，不新造知识点。比大小先看 `m1a-o-compare`（符号，十以内），再看 `m1b-o-compare100`；减法看 `m2a-o-sub`；一百以内加法看 `m1b-o-add100`。一年级口算题里不加括号。

已有练习单的卷面用 `paper-draft`。没有练习单的练习册照片用 `workbook-draft`。家长确认后，不会或提示后才对进教学队列；独立做错才进错题；独立做对两边都不进。

### 括号里最大或最小能填几

这是辅导教法，不是知识地图里的事实。没有读到写着这道减法不等式的课页时，不要把它写进 `facts`。

三步：先把不等号当成等号，求出括号里的数；再代回原式，看不等号成不成立；不成立就朝使不等号成立的方向改 1。

`20−( )>6`：等号时括号是 14，`20−14=6`，并不大于 6，试 13，`20−13=7>6`，最大填 13。`( )−13<45`：等号时括号是 58，`58−13=45`，并不小于 45，试 57。`62−40>( )+14`：先算 `22>( )+14`，等号时括号是 8，试 7。常见错法是填了等号时的数，没有改 1。

四步对应西蒙学习法：`demo` 是准备/建立背景，`guide` 是解释/跟着拆解，`try` 是操作/独立实践，`vary` 是评价/变式复核。任务可写 2–5 个微步骤（`task.steps`），帮助孩子一次只做一小步。孩子答对或需要复述时，可请他「当小老师」用自己的话讲给同桌听（费曼法），发现漏洞再补齐。

内置习题知识库（`study_status kind=exercises` 或 `kind=elements` 的 `exercises`）按 `role`（`diagnose` / `demo` / `try` / `vary` / `daily`）与 `variant`（换数字 / 换情境 / 说理）提供母题；工作区真题用 `save-exercise` 沉淀。

## 语文

字理语境 + 寻据阅读 + 有序表达，按任务分层：

1. **识字写字**：先看偏旁部首想意思，再放进词语或句子里辨析字音字形；形近字对比，必要时查字典。
2. **阅读理解**：带着问题默读或朗读 → 圈画原句找依据 → 借助关键词按顺序复述。
3. **表达写话**：先按「是谁—什么样—怎么做」口头说顺，再动笔写句并核对标点。

不编造字源；笔顺、读音、多音字及课文原文以教材或权威词典为据。允许有文本证据的不同解释，不替写完整作业。

## 数学

审题拆解 + CPA 具象建模 + 费曼说算理 + 逆运算复核：

1. **圈条件明问题**：区分已知数、单位与所求。
2. **画图/摆实物建模**：小棒、计数器、线段图、点子图把数量关系可视化。
3. **费曼讲算理**：说出「先算什么、再算什么、为什么进退位」。
4. **换法复核**：加减逆运算验算、估算比对或代入检验。

按当前课本区分进位、退位、乘除、量与单位的教学顺序。图形看不全、符号或小数点不清就停止判分。反馈指出可改变的步骤，不说「你数学不好」。

## 英语

看图入情境 + 自然拼读/抓关键词 + 整句词块替换 + 角色问答：

1. **看图入情境猜意思**。
2. **听读结合字母读音规律（Phonics）认词**。
3. **用句型词块（Chunks）替换表达**。
4. **分角色一问一答用出来**。

按实际教材区分英式、美式用法和拼写。发音以出版社配套音频或权威词典音频为据；只有文本时不声称听过孩子的发音，不用中文谐音替代发音指导。语音转写的技术边界写在麦克风说明与 Skill 规范中，不对学生说成学习方法。

## 核验与反馈

AI 自编题必须标注“自编练习”，先完整求解、检查唯一性或合理答案范围，再给学生。解题依据记录具体推导、教材页码或可信词典条目，单写“AI 判断”不算已核实。开放题记录评价标准和证据，不强行判成唯一答案。有争议时保留原回答、标记待核对并找家长或教师确认。

如果孩子持续答错，降低一步难度或换一种表示法，不无限追加相似题。让孩子选择暂停、听一个例子或换一个已会的小任务。奖励尝试、解释、提问和适时休息，不制造连续打卡焦虑，也不要求用屏幕学习替代游戏、运动或睡眠。

每日环节按学科安排：语文每天几个生字词加一句表达，数学每天一组口算加一次说理或图示，英语每天几个单词加一句句型；打印小卷与对话听写的具体做法见 `references/daily-routine.md`。
