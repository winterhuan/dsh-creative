# 源文观察角度

按本次分析问题选择角度，用原文位置与短引句回答；不是按写作模板重写源文，也不将工业范式当合格线。

| 问题 | 核实的文本变化 |
|---|---|
| 人物是否成立 | 主角想要什么、受何约束、作何选择、付出什么；区分欲望与表面标签，反差是否有前因 |
| 人设是否有层次 | 缺点、能力、信念与行动是否互相制约；成长是否来自选择和后果，而非新增标签 |
| 关系是否推进 | 冲突、联盟、亲密与权威如何变化；每方是否有独立目标，声线与筹码是否可区分 |
| 读者为何在意 | 面向何种读者与缺口，开头如何许诺，过程如何加压，结尾兑现了什么；市场流行不能只凭单篇推定 |
| 段落与小节为何留人 | 信息差、未完成行动、危机或关系问题具体在哪形成、推进和回收；没有新钩子时是否有蓄力或后果 |
| 写法是否有效 | 叙述距离、对话、动作、回忆、信息顺序怎样影响读者理解，少对白场景靠什么推进 |

短篇里观察背叛的类别、代价与关系后果是否升级；冷热反差来自筹码和选择，不预设主角冷静或反派歇斯底里。回忆应改变当下判断，审问应迫使对方选择或暴露矛盾，不能只数出现次数。小节长度服从动作链，不用字数或爆点配额判断。

分析人物地位时，可观察称呼与待遇的变化。例如修仙故事中的“蝼蚁→道友→前辈”呈现地位改变；它只是一个可识别机制，不要求其他作品具备同样阶梯。情绪词、标点、身体动作或对白占比都须结合具体效果，不能单独证明 AI 来源或质量。

需要结构、钩子或悬念的分析问题，分别读 [结构功能](analysis-short-patterns.md)、[小节衔接](analysis-short-hooks.md)、[悬念](analysis-short-suspense.md)。需要设计新故事时加载 `story-write`；本任务只解释源文事实及可迁移条件。
