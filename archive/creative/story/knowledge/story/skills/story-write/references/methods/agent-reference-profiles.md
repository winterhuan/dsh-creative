# Agent 参考资料索引

> 按当前任务和篇幅定位所需资料。已获得相关内容时不重复读取；只加载能解决当前问题的章节，不逐行执行阅读清单。创作技法与数值示例均是建议；用户约束、已确认事实、批准细纲和读者价值验收仍由对应流程约定。

## 选择规则

1. 参数明确写“长篇 / 连载 / 章纲 / 日更”时选择 `long`。
2. 明确写“短篇 / 单篇 / 小节大纲 / 盐言 / 小程序短故事”时选择 `short`。
3. 参数未写明时，用项目产物判定：`大纲/细纲_第XXX章.md`、`追踪/` 属于 long；`小节大纲.md`、单文件 `正文.md` 属于 short。
4. 新建项目按调用方给出的篇幅和交付目标选择；`story-write` 同时服务长篇和短篇，不能只凭技能名判断。
5. 篇幅未定且影响方案时，报告缺失信息；可先处理不依赖篇幅的任务，不同时预加载两套资料。
6. 无需输出固定 profile 标签；只有篇幅判断影响结论时才说明依据。
