# 短剧视觉设计

根据当前材料直接进入用户要的任务。每份文档保持独立用途；合并入口不意味着每次都完成四个阶段。资源路径从 DSH 资源根解析，用原生 `read` 只读对应模式。

| 模式 | 输入与产物 | 工作流 |
|---|---|---|
| 视觉设定 | 剧本 → `视觉设定.md`，身份、造型、地点、道具与持续状态 | `references/assets/workflow.md` |
| 图片提示词 | 视觉事实 → `图片提示词.md` 的 `IMG-*` 可复制条目 | `references/image-prompts/workflow.md` |
| 分镜 | 剧本与必要视觉事实 → `分镜.md` 的 `SHOT-*` 及冻结关键帧 | `references/storyboard/workflow.md` |
| 视频提示词 | 分镜与参考准备 → `视频提示词.md` 的 `MOTION-*`，按需音乐意图 | `references/video-prompts/workflow.md` |

所有产物位于 `剧集/<EP>/`。图片提示词与分镜可分别从视觉事实进入，不互相等待。明确请求跨多种视觉产物时，在同一任务内完成依赖更新，不重复切换技能或新增对账文件。

- 剧本拥有故事语义；视觉设定拥有可识别身份与持续状态；分镜拥有起止瞬间与镜头职责；视频提示词展开已确认的状态变化。变更不得静默改写上游剧情。
- 保留 `VISUAL-*`、`IMG-*`、`SHOT-*`、`MOTION-*` 稳定身份。`IMG-*` 是提示词条目，不是已生成图片；真实图片使用独立 `REF-*` 槽位。
- 涉及真实参考、槽位和跨文档绑定时读 `references/visual-reference-bindings.md`。有可用图就核实用途并更新绑定；缺图如实标记，不能伪造路径或自动改成文生视频。
- 每镜起点、动作与终点应连续可实现；关键帧只描绘起点。已知模型的原生时长在分镜时生效，超限按状态闭合点调整；未选模型不猜限制。
- 可复制正文不含资源路径、流程说明或质量报告。说明语言、提示词语言、口语语言与画内文字分别遵循项目约定，不互相推断。
- 已声明的连续性锁和真实信息释放边界必须保留；技巧、镜头数、固定比例不作为通用门禁。

从图片/分镜到最终视频的参考输入必须真实准备好，或由创作者明确选择文生视频。支持续接的连续段使用上一段实际视频与实际尾帧；尚未生成时可保存“待续接、不可提交”的后段草案，不能冒充最终输入。

只创建请求需要的文档。普通修订直接完成；改变既有剧情或视觉方向的真实分叉才澄清。实际生成图片、视频、配音或音乐转 `short-drama-produce`，本技能与参考准备均不构成生产授权。
