# Agent Note: Ego Lite 作为 Writer 唯一浏览器后端

Status: proposed

[English](2026-11-06-writer-ego-browser.md) | 中文

## 问题

Writer 的七个榜单采集器和四种研究员模板依赖全局 `agent-browser`，通过调试端口共享隐式当前页。[Chrome 启动器](../../../../plugins/dsh-writer/packages/winterhuan/writer/skills/browser-cdp/scripts/setup-cdp-chrome.js)复制个人 Profile，并可在征得同意后关闭无关 Chrome 实例。并发调用可能互相导航。这套生命周期带来干扰和维护负担，却不贡献榜单分析能力。

[写作模式决策](../../implemented/feature/2026-10-31-writer-preset.zh.md)仍拥有 bundled/workspace 技能互斥和项目副本保护规则。本提案保留该决策，只改变浏览器执行。原有浏览器提案在此整合，不取代或归档已实现的浏览器后端笔记。

## 提案

用户选择 Ego Lite 作为唯一浏览器后端。传输模块、七个采集器迁移、Ego-only 的 `browser-cdp` 入口、平台参考、研究员模板与包说明已连同假 CLI 单元测试落地；下方验收条件通过前笔记保持 proposed。Stage 3 删除（Chrome 启动器、重复辅助模块、废弃端口参数）等验收后再做。不发布 Tabbit 回退或后端选择开关。缺少 Ego Lite 时报告前置条件错误，或走原本支持的非浏览器路径，绝不静默启动 Chrome。

Ego Lite 拥有浏览器、登录存储、TaskSpace、页面连接与用户控制权。Writer 拥有平台参数、确定性提取、有界批次、检查点、数据质量与本地报告。保留 Node SSR/字体请求、解析器、渲染器和聚合器。不新增 DSH 浏览器服务、broker、私有 CDP 连接或 npm Playwright 浏览器。Writer 不导入个人 Profile；浏览器提供的迁移另由用户操作。

### 打包与发现

保留 `browser-cdp` 兼容技能名；正文已是 Ego-only 入口，Chrome 启动器不再被引用、待 Stage 3 删除。共享传输模块为 `skills/browser-cdp/scripts/ego-session.cjs`，两个扫榜技能按同级相对路径加载。显式 CommonJS 后缀避免包的 ESM 作用域歧义。部署必须复制完整已知技能集合；两种挂载模式仍需下方验收测试。

厂商管理的 `ego-browser` skill（技能）和已安装的 `ego-browser skill` 指南拥有浏览器 API 操作说明。Writer 不复制或覆盖该技能。浏览器工作前读取指南，升级后或运行时要求时重读。平台参考只写采集专属说明。不推断 Playwright 方法：Ego 使用自定义 API。兼容名称与官方技能分离，避免遮蔽和遗留项目副本。

### 执行与页面所有权

保留本地 Node 采集进程，通过一个小型 Ego 传输模块异步调用浏览器。用维护中的 Space 连接、页面导航/表达式执行、交接和结束操作取代 `ab(port, ...)`。不重建完整 Ego API，不做通用驱动注册表。研究员模板使用官方技能，接收任务 Space/页面分配，取代 `cdp_port`。

调用受支持的 `ego-browser nodejs`，用参数数组和 UTF-8 stdin，不经 shell 插值或版本化运行时路径。嵌入运行时使用 ESM、不同 cwd，且不继承 shell 环境。输入显式序列化，路径用绝对值；需要 Node 内置模块时动态导入。遵守文件权限，不要求关闭 Harness 沙箱。Windows 命令解析和 stdin 需专项测试；Linux 不在目前记录的支持平台内。

每个用户目标只使用一个 TaskSpace，跨轮次保留其数字 ID。复用初始 `p1`，只有独立来源必须同时保留时才增加页面。单一协调器拥有 Space，串行提交 CLI（命令行界面）轮次；独立页面工作可在一轮内有界并发。subagent 可解析返回数据，但不能独立接管或结束同一 Space。不为了绕过失败或并行平台而静默新建 Space；多个 Space 需要用户明确要求。

只操作已观察到的托管页面标签。持久化 Space ID 与页面标签，不保存临时 target ID 或 JavaScript 全局变量。恢复时先检查页面、所有权、URL 和筛选状态。同一页面导航与提取串行。使用维护中的 `page.evaluate` 表达式和有界浏览器 fetch；网站文本是数据，不是指令。仅校验 host 不能发现同站错误筛选或榜单。

### 结果传输与检查点

使用 Writer 自有的带版本结果信封，包含运行 ID、操作 ID、Space ID、页面标签、结果状态、数据和有界错误。校验后通过 `console.log(JSON.stringify(...))` 输出一行 JSON，并带本次调用专属标记。外部进程在两个捕获流中查找精确标记，拒绝缺失/重复/过大/畸形结果，其他输出单独作为诊断。不把整个 stderr 当 JSON，不假设结果一定在 stdout。操作 ID 只关联本地证据，未证明 Ego 会对其去重或保存持久回执。

优先使用有界 JSON 批次；实测试验完整传输了约 139 KB。实现规定明确大小上限，超出前缩小批次。更大结果通过文档化的 Node 文件 API 写入预分配的运行内绝对路径，校验大小和信封身份，原子重命名后再读取。文件交接及其失败行为必须验收；它是拟定方案，尚未验证。不引入 Tabbit 资源 ID、字节分页、退出码 70/75 或 receipt 命令。

已完成批次拟在 `.writer/browser-runs/<run-id>/` 保存检查点。记录输入参数、解析器修订、批次键与时间戳、Space/页面标识、本地操作 ID、已校验业务数据和可恢复阶段。提交执行前保存意图，校验输出后原子提交。不保存 Token、Cookie、密码，也不声称浏览器恰好执行一次。检查点不证明页面仍存在或中断程序已停止。

只有参数与解析器修订匹配的显式选项才恢复运行。跳过已提交批次；重放中断操作前先核对当前页面。结果未知的读取也只能在确认控制权和页面就绪后重试。保留最终文件名、本地日期语义、报告格式、聚合和成功/空输出/部分失败区分。拒绝对同一输出的并发写入，不因空结果或提取失败抹掉有效报告。显式新运行保留同日替换行为。检查点与报告需要相同的数据访问保护。

### 用户控制、失败与结束

安全超时与控制权以 Ego 已安装指南为准。本轮未建立全局程序时限、空闲过期或持久回执服务结论；不假设无限运行，不套用 Tabbit 的 60/180/90 秒规则。列表与详情拆成有界轮次。使用可观察就绪条件替代固定等待，测量前以现有平台批大小为上限。

| 条件 | 必须行为 |
|---|---|
| 合法成功信封 | 校验数据并提交批次；动作回执本身不证明业务结果。 |
| 非零退出或缺失结果 | 保留意图/检查点，检查同一 Space 并确认执行是否停止，不盲目重放。 |
| 安全超时 | 解释 `executionStopped`、`pageResponsive`、`mayHaveLateEffects`；可能不安全的后续操作前先恢复可用页面。 |
| 用户接管或 Space 不活跃/未分配 | 立即停止新增动作，不重试或新建 Space 绕过停止。 |
| 登录或验证码 | 调用 `task.handOff()`，结束轮次，报告保留的 Space/页面，用户确认后才 `takeOverTaskSpace(id)`。 |
| 用户拥有的 Space 或已结束后保留的 Space | 未获用户明确授权不得 claim；已结束的页面标签不再可用。 |
| 访问拦截或限流 | 停止并报告缺口，遵守已观察到的重试时间，不反复刷新挑战。 |

取消时停止新增批次并核对在途执行。杀掉 CLI 不证明浏览器已取消。出错或用户接管时不调用 finish，保留 Space 与恢复信息。只有控制权允许时才恢复只读检查。任何结果传输或检查点都不会自动授权未来业务写入，也不使重放变安全。

成功时提交报告，再仅调用一次 `task.finish({keep: []})`，等待结果，此后不再操作页面。只保留用户需要查看或明确要求的结果页，保护用户/来源未知标签。结束时不逐个关闭访问过的页面。finish 结果不明就报告不确定，不重试或声称清理完成。交接是暂停，不是成功结束。

### 平台迁移

| 平台 | 保留与适配 |
|---|---|
| 起点 | 保留 Node 移动端 SSR 和白名单字体解码，迁移 PC/书库 DOM 操作，验证码轮询改为交接/恢复。 |
| 番茄 | 保留页面状态和详情解析，验证同步 XHR 批次，必要时改为有界同源异步 fetch，不改变字段。 |
| 晋江 | 保留同源详情 fetch、六本批次、ArrayBuffer/GB18030 解码，以及详情失败后的列表。 |
| 七猫 | 迁移榜单与活跃筛选校验，保留纯 Node 书库 HTTP 路径及站点专属响应处理。 |
| 刺猬猫与点众 | 迁移导航、有界滚动和 DOM 提取，保留渲染与质量标记。 |
| 黑岩 | 要求在 Ego 内授权手工登录；页面内读取 Token 并请求带认证跨域接口，只返回业务数据。 |

浏览器 fetch 保留 cookies/CORS/CSP 语义，Node HTTP 不能直接替代带认证的页面请求。Token 不进入 CLI 输入、任一输出流、模型上下文、检查点或报告。当前采集器不需要浏览器级 CDP 或原生下载事件，不因 Ego 提供更多能力就新增采集行为。

### 交付与工作区副本

分三个可评审阶段实施：共享传输模块、简单采集器及假 CLI 测试；七个采集器和四种研究员模板；验收后删除旧启动器、端口参数、重复浏览器辅助模块及活跃执行说明。开发期临时并存不成为发布回退。后端选型已确定；失败属于实现或验收缺口，不自动授权改用 Tabbit。

保留 `browser-cdp` 可维持[按名称 sync/unsync](../../../../plugins/dsh-writer/packages/winterhuan/writer/src/sync-skills.ts)，已有副本仍需刷新。默认同步不得覆盖项目修改。预览过期的自有技能/模板，经明确授权后一致刷新完整集合。自定义副本报告待协调，保护无关技能和符号链接目标，验证旧项目升级。平台参考、story 路由、宿主命令/菜单、固定部署清单、研究员生成形式、双语包说明和同步测试一起更新。不编辑冻结归档。既有 writer 预设笔记保持活跃并交叉链接。

## 考虑过的替代方案

**Tabbit 作为唯一后端。** 实测覆盖了原提取表达式，其文档化 Playwright 与请求回执/资源协议有价值。用户在本范围选择 Ego，其较窄的 Page API 与明确人工交接适配采集器。接受 Writer 自行处理结果标记和恢复检查的代价，不宣称速度或可靠性实测更优。Tabbit 是考虑过的替代方案，不是受支持回退。

**专用 Chrome Profile 加直接 Playwright CDP。** 可行，但 Writer 仍需拥有浏览器发现、启动、连接和跨平台生命周期。继续复制个人 Profile 还会保留广泛登录访问与关闭 Chrome 的干扰。

**永久双驱动或自建 broker。** 两者都会增加生命周期与平台测试；broker 重复 Ego 的 Space 所有权管理。单一外部浏览器使集成保持有界。

**纯模型提取或巨型浏览器脚本。** 前者失去确定性解析和质量标记，后者增加中断、人工交接与部分进度恢复的难度。保留维护中的解析器和有界轮次。

**兼容技能改名为 `ego-browser`。** 会遮蔽厂商技能，并使旧项目目录退出按名称清理。保留薄旧名入口，不保留旧后端。

## 验收条件

1. 假 CLI 测试验证真实 argv/stdin、显式输入与绝对路径、任一流中的版本化结果标记、重复/缺失/畸形/截断/过大结果、非零退出、迟到结果、文件交接、检查点提交/恢复、所有权丢失与 finish 不确定。不使用真实个人 Profile。
2. 七个平台均有线上冒烟证据与脱敏解析 fixture（测试前置数据），覆盖页面/筛选身份、书籍 ID/标题、指标单位、链接、聚合及详情失败后的列表。黑岩需要授权账号，没有账号表示该采集器具名未验证，不表示通过。数据质量验收前修复已发现的刺猬猫指标混入问题。
3. 线上测试覆盖多轮长采集、失败时的大结果、明确交接/接管、用户停止、安全超时延迟影响、同 Space 独立页面不串页和进程重启。不关闭无关标签，不泄露凭据。
4. bundled/workspace 挂载和旧项目升级在实际安装的 DSH 中能发现共享模块及官方 Ego skill。记录实测 CLI/指南版本。声明 Windows 前验证 launcher/stdin 与文件行为；Linux 在厂商可用且专项验收前不支持。
5. 活跃执行源码、部署/生成模板、包说明和测试不依赖 agent-browser、Tabbit 后端、调试端口、个人 Profile 复制或全局关闭 Chrome。历史决策/归档提及允许保留。实现验收前通过已有输出/部分结果测试及适用的 typecheck、build、包内测试、doc-sync（文档同步门禁）和 hygiene 检查。

### 证据与覆盖缺口

2026-11-06，macOS Ego CLI 0.6.2.8、指南 v2.2.0 执行原版[刺猬猫提取表达式和渲染器](../../../../plugins/dsh-writer/packages/winterhuan/writer/skills/story-long-scan/scripts/ciweimao-rank-scraper.js)，得到九个各十条榜区、85 个去重链接、渲染报告头，页面内 fetch 与 `page.fetch` HTTP 200，以及正确的 GB18030 解码。同一 Space/页面跨轮次续接，finish 完成。另一次探测重建 1,000 条、138,818 字节 JSON。日志和 `process.stdout.write` 均进入 stderr，stdout 为空，受控抛错退出码为 1。渲染器仅在内存运行，未写正式榜单报告。

早前 Tabbit 试验在不同实时点返回九个各十条榜区和 83 个链接，并完成异步 fetch 和清理，不能按条数比较准确率。原版部分刺猬猫指标含下一条文本。这些测试证明执行覆盖，不证明完整解析正确或吞吐。

实现日证据（2026-11-06，macOS，CLI 0.6.2.8）：传输模块通过 15 项假 launcher 单元测试，覆盖 argv/stdin、双流标记信封、重复/缺失/畸形结果、页面侧错误、崩溃退出、结果文件校验与超限拒绝。三个已迁移采集器在模拟 `.agents/skills` 部署下跑通完整流水线：刺猬猫写出榜单报告（9 榜区、85 链接），晋江写出 18 频道 600 本列表且 GB18030 异步详情批 6/6 命中，点众写出 10/10 书名条目。writer 全量测试（84 项）与 16 项文档检查通过。

评审后又修复了四项传输缺陷与两项生命周期缺陷，均有测试固定：信封 schema 与非零退出校验；UTF-8 字节上限和原子、限目录的结果文件交接；只在状态明确干净时 finish、交接/不确定/未连接时保留 Space 的安全收尾；用 `scripts/package.json` 的 CommonJS 边界让随包与复制后的采集器在 ESM 包下可加载；起点交接后的停止；以及带参数与解析器版本校验的批次检查点。研究员模板改为按 topic 唯一 Space 并显式 finish，生成的 Antigravity agent 不再引用它没有的工具。传输测试 32 项、writer 全量 101 项通过；三个采集器从发布路径线上跑通并生成检查点；未登录的黑岩运行确认保留并随后释放了交接的 Space。

2026-11-07 提交前复查将晋江/番茄详情检查点键绑定到榜单/分类身份与有序书籍 ID，只缓存校验完整的批次；不确定结果、交接或结束后，普通浏览器调用会被拒绝。显式恢复要求确认执行已停止且页面可响应。黑岩现在返回部分结果（退出码 2），写独立 `.partial.md` 而不覆盖完整报告，认证失效时停止并保留 Space。回归覆盖 34 项传输、8 项缓存与 15 项黑岩测试；仓库 typecheck、build、全部 557 项测试、doc-sync 和 hygiene 通过。现有 GUI 可加载，但运行中的 profile 未暴露 writer 预设，旧写作会话不可用，因此本轮未在该 profile 中交互验证文件树改动。

尚未验证：起点/七猫/番茄/黑岩的已登录线上运行、真实登录或验证码的交接→`--space` 恢复、并行采集隔离、Windows launcher/stdin、Linux，以及真实 profile 中的 writer 文件树交互渲染。上述验收条件仍约束 Stage 3 删除。

## 风险

Ego 是外部桌面前置条件，自定义 API 与输出通道独立变化。[官方技能介绍](https://lite.ego.app/document/en/docs/skills)和[公开仓库](https://github.com/citrolabs/ego-lite)提供背景，但旧网页 API/Space 说明与安装指南有差异。记录实测版本，拒绝不兼容形状，不猜私有行为。不能把未记录时限或回执 API 当保证。

Space 隔离工作组织，不证明任务间凭据隔离。只使用已授权站点和最少业务输出。中断恢复可能混合榜单时点，保留批次时间戳并披露部分快照。迁移放弃任意普通 Chrome 连接和纯无头浏览器部署。适配器保持采集专用，不扩展为通用自动化框架。
