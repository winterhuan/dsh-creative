# Agent Note: Student 单元课程与完整互动课优先学习规格

Status: proposed

[English](2026-11-27-student-unit-course-spec.md) | 中文

## Problem

孩子点击开始学习，需要得到连贯的教学内容，并能在之后恢复课程、补讲和复习。现有的目标、学习段、原生对话和课堂工具不足以保证这个流程：开始学习可能只进入文字摸底，课程入口、所选目标和教学需求未形成稳定衔接，按钮还会展示内部执行协议。

2026-11-27 的 qiqiStudy 会话 `session-a18bdfa5-9cd2-466c-8cd5-fe6fe2fd7c69` 中，开始语文学习耗时约 775 秒，回答“幕”耗时约 368 秒；两次分别经过 30 和 11 个模型步骤。该次会话没有调用完整课堂生成或内容呈现工具。这是已观察的失败基线，不证明外部课堂服务故障，也不代表所有学习请求的性能。

## Proposal

本 spec 规定待实施的产品行为、数据责任与验收条件。新目标默认先完整互动课，补讲和后续复习使用小课；单元课程管理多个可分次完成的课节。现有工具接口可复用，但不能据此把本 spec 的端到端能力标记为已实现。

### 范围与既有决策

本 spec 部分调整[每日学习方案](2026-11-25-student-daily-learning-plan.zh.md)中的冷启动路径：缺少证据不再自动把新学转为独立摸底任务；必要的简短了解嵌入课程。保留学校进度限制、跨科推荐、有限复习和主动收尾。

本 spec 细化[OpenMAIC 学习闭环](2026-11-22-student-openmaic-learning-loop.zh.md)的课程选择和呈现顺序，新增单元组织与分节恢复；原提案继续拥有课堂反馈导入、母题归并及能力映射。保留[原生学习架构](../architecture/2026-11-12-student-learning-flow-architecture.zh.md)的原生会话、agent 直接写正式文件、只读 CLI 校验与应用独立读取，不在本期引入通用写入工具或另一套辅导执行器。

以上三份提案均为部分细化，继续保留并交叉引用。现有[取消时长限制](../../implemented/feature/2026-10-30-student-overhaul.zh.md)、[学校进度](../../implemented/feature/2026-10-14-student-school-frontier.zh.md)及[课堂传输与学习证据分离](../../implemented/feature/2026-10-28-student-openmaic-lessons.zh.md)的决策仍有约束价值，不归档；后者的历史 shell 路径不作为当前接口依据。本文不改掌握阈值、复习间隔、既有题库，不实施能力树整体迁移，也不新增后台自动备齐整单元课程。

### 课程层级与生成责任

课程覆盖与能力掌握分别表达。课节可以覆盖相关能力，但每项能力独立保留范围和评价依据；不能把整篇课文或整个单元当成一个掌握结果。

| 层级 | 内容与生成者 | 生成时机与复用 |
| --- | --- | --- |
| 单元课程 | Student 模型依据教材建立课节目录、顺序、目标与材料引用；它是组织记录，不是外部课堂。 | 确认教材和单元内进度后，用户首次开始该单元时建立；之后复用目录。 |
| 完整互动课 | Student 准备明确的教学需求，调用 `openmaic_generate`，由 OpenMAIC 服务生成课堂。 | 首次学习当前可学课节时生成一次；暂停、刷新和换会话继续原课堂。 |
| 复习或补讲小课 | Student 模型编写针对性内容，按需调用 `openmaic_render`、`openmaic_slide` 或 `openmaic_widget`。 | 针对真实困难补讲；复习先回忆或做题，需要时才讲解。已有适用内容优先复用。 |
| 单元综合课 | Student 汇总实际学习覆盖和作答证据，调用 `openmaic_generate` 组织综合课堂。 | 用户确认单元学完或明确准备单元测验时按需生成；未覆盖部分须说明。 |

“整个单元的大课”默认指上述可分次学习的课程集合，不是一节必须连续完成的长课。一篇课文可按教学目标拆成多个课节，拆分应有教学理由，不以固定页数或分钟数决定。

### 教材与学校进度

生成教材对应的单元目录前，必须确认教材版本、单元目录、用于教学的材料和学校在该单元内的位置。学校位置至少区分刚进入、正在学习指定课文或主题、已学完；已确认信息复用，只询问真正缺失的部分。

知识地图只提供目标候选，不能代替教材正文。材料未齐时显示缺少的资料，允许保存待补齐目录草稿；不得宣称已经建立教材对应的完整单元课。用户仍可明确选择范围内的基础目标课，并标明自编例子和材料限制。

默认只为已确认校内进度内的当前课节生成课堂。单元目录可显示后续课节，但不能据此自动预习；超出进度的学习沿用家长确认规则。家庭学习完成不会自动推进学校进度。教材修正时，未开始的目录可修订；已生成课堂、原题和作答保留原材料版本及关联。

### 孩子的学习主线

进入学习页先恢复当前活动。孩子明确选择新课节时，暂停旧活动并保存恢复位置，随后启动新活动；旧科目的建议不能覆盖本次选择。待同步的课堂或待评价回答继续属于原活动，允许暂放后换内容。

| 当前情况 | 主按钮或入口 | 可观察结果 |
| --- | --- | --- |
| 当前可学课节尚无课堂 | 开始互动课 | 保存课程归属与教学需求，提交一次完整课堂生成，并显示真实状态。 |
| 已提交但未就绪 | 查看生成进度 | 查询同一任务；显示等待、失败或需要家长处理的原因。 |
| 课堂已就绪或暂停 | 进入互动课／继续互动课 | 打开原课堂，并恢复可核验的位置。 |
| 课堂结束、证据待同步 | 查看学习反馈 | 读取原课堂记录，显示同步状态及已核验的结果。 |
| 当前目标有真实困难 | 补讲一下 | 针对困难准备小课，再按剩余额度检验。 |
| 有到期复习 | 复习一下 | 先回忆或尝试；正确且满足本轮要求即可收尾，需要帮助时补讲。 |
| 本次活动结束 | 今天先到这里 | 显示简短小结；再学一点或换内容由孩子主动选择。 |

完整互动课至少包含明确目标、必要的简短了解、讲解与示范、引导练习、独立尝试和总结。生成前的需求必须包含这些要求；生成后核对可读取的内容和题面。缺少必要内容、超出范围或答案依据冲突时，不标为可学习，保留问题供修正。

不把所有能力统一变成反复追问。已有有效作答应复用；遇到不会的内容要讲解，不能为了补齐字段无休止加题。每轮最多三道新检验题的既有额度需在课前需求中约束，并在可读取的课堂题面中核对；讲解例子和有提示的引导练习应明确标注，不冒充独立检验。若提供方无法满足此限制，课堂不通过验收，不能通过另建学习段规避额度。

学习可以随时暂停或结束，不新增每日分钟上限。课节结束表示本次活动收尾；长期掌握仍取决于有效作答及既有规则。观看、动画、课程生成成功、组件分数和“我学完了”都不能独立授予掌握。

### 单元课程的建立与收尾

建立单元课程时只生成整体安排和当前需要的课节；后续课节在准备学习时结合此前表现生成。启动下一课节必须由孩子明确继续，不因返回页面或前一课完成而自动提交外部生成。

单元目录分别展示课节是否已生成、学习是否已结束、证据是否待核对，不能用一个完成百分比替代三种事实。单元综合课从原课堂、原回答和困难中取材，复用已核验材料，优先覆盖关联与迁移，不逐题重做整个单元。

学校已学完整个单元但 Student 记录不完整时，允许用户启动综合课；需求必须说明证据缺口，不虚构已学历史。仅有“正在本单元”的确认时，不自动生成综合课。综合课完成后保留薄弱点与后续复习，结束单元不清空历史困难。

### 生成、异常与恢复

外部任务状态与学习状态独立。生成需要区分未提交、提交结果未知、生成中、就绪和失败；学习需要区分未开始、学习中、暂停和已结束。反馈另标同步中、待核对或已核验，不把任一状态推导为掌握。

| 情况 | 必须行为 |
| --- | --- |
| 双击、刷新、跨日或更换原生会话 | 依稳定归属读取同一课程和原任务；不得再次提交。 |
| 提交超时且不确定是否受理 | 保留原提交身份并进入结果未知；查询或恢复原任务，不自动重试创建。 |
| 登录过期、身份变化或权限拒绝 | 保留任务与学习位置；提供家长恢复入口，不循环登录，不改绑其他学生。 |
| 已确认任务失败 | 展示可执行恢复动作；同任务重试须有服务明确支持，不能假设当前接口支持。 |
| 需要重新生成 | 仅在旧任务结果已确定且用户明确选择后，创建替代版本及独立生成归属，保存旧引用；不得覆盖已有作答。 |
| 用户选择先用小课 | 明确标为临时替代，不标记完整课已生成或已学完；原任务继续可恢复，迟到就绪结果不打断当前学习。 |
| 课堂已就绪但业务文件尚未保存 | 从已有受保护传输记录核验并补齐引用，不创建另一堂课。 |
| 播放器不能恢复精确页码 | 恢复同一课堂，明确提示位置未同步；只使用可核验或用户明确选择的章节，不声称恢复成功。 |

生成等待期间展示服务返回的真实状态和最近检查时间，不编造百分比或剩余时间。自动状态读取不得触发生成、学习文件写入或模型轮询循环；正式文件的状态更新仍经原生流程校验。Host 与浏览器的认证分别验证，凭据不进入提示词、业务文件或课堂 URL。

### 数据归属与兼容

以下是待实现的最小逻辑记录，不是现有字段清单。优先扩展既有正式文件和校验器；新建单元索引的具体 schema、版本与迁移应在实现阶段作为一项完整变更，不平行复制作答库。

| 记录 | 最小责任 |
| --- | --- |
| 单元课程索引 | 稳定课程 ID、学生与学期、教材及来源版本、单元、目录修订、稳定课节 ID、顺序、目标与范围、课堂引用。 |
| 课堂记录 | 复用 `.study/openmaic-lessons.json` 的归属和生命周期；关联课节、材料版本、教学需求摘要及版本、原始学习段、外部任务和课堂身份。 |
| 学习活动 | 复用每日计划和学习段保存本次用途、当前课节／题目、暂停位置、结束状态以及原回答、帮助和评价。 |
| 小课内容 | 保存可复用内容或稳定资源引用、来源课堂／目标、适用范围及内容版本；生成内容本身不是学习证据。 |

生成归属与后续学习活动分开：原课堂绑定的学生、学期、学习段及外部任务不可被复习活动改写。复习建立自己的活动并引用原内容；迟到反馈归回原活动。单元综合课有自己的生成归属，同时引用来源课节与证据。

首次加载旧档案只读，不自动生成单元、课堂或补造学习历史。升级迁移按下节规则直接删除无效内容并修改关联，不新增旧课程归档功能。只有材料与归属可核验的旧课堂才纳入新课程目录，不按标题猜测归属。迁移在副本验证，备份原文件；重复执行不重复记录、改写原回答或授予掌握。

多文件变更使用相关文件版本检查，并在一次原生操作中协调旧活动暂停、新活动和计划关联。校验失败或进程中断时，应用保留最后已校验的视图并提示恢复，不能展示半完成切换。冲突后重新读取相关文件，保留另一会话的新回答，不整文件覆盖。原回答仍先于评价持久保存。

### 旧内容删除与修改

清理随升级迁移执行，页面读取不触发清理。判定依据是实际产物、有效性和引用关系，不以是否调用过 `openmaic_generate` 单独决定删除。旧流程通过其他方式生成的真实课堂仍可复用；只有成功日志不足以证明课堂可用或归属正确。

| 旧内容 | 直接处理规则 |
| --- | --- |
| 冒充完整课程的提示词、文字教学草稿及无实际产物的课程条目 | 删除课程条目和无引用的对应文件，移除推荐与目录引用；若内容是已作答题目的唯一题面或评价依据，先保留到原证据记录，核验后再删除冗余文件。 |
| 空学习段、无作答且已过时的计划任务 | 删除已确认废弃的记录，同时修正每日计划、当前活动及跨日引用；仍在使用的未答题或生成中的活动不按“无作答”删除。 |
| 有真实作答的旧文字教学活动 | 保留原题、回答、帮助、日期和评价关联；将失效活动结束或从当前推荐中移除，准确标注为历史文字练习，不标为已完成互动课。 |
| 可核验且可用的旧真实课堂 | 保留原生成归属，补齐有依据的材料与课节关联后复用，不因缺少工具调用记录而删除。 |
| 已确认无效的旧课堂入口或失效引用 | 从当前课程目录和推荐中删除；仍被真实作答引用的课堂身份及题面版本保留在证据所需记录中，不级联删除证据。 |
| 暂时无法核验的课堂或提交结果未知的任务 | 保留恢复身份并移出可学习推荐，显示待核验；网络失败、暂时登录异常或索引为空不能作为删除依据。 |

新流程不得继续恢复已删除的废弃任务。删除前核对所有引用，删除与计划／目录修正作为同一次迁移处理；完成后独立读取并校验无悬空引用、无双重当前活动、无真实作答丢失。不改教材和学校进度，不为填满新目录生成替代课程，不改写历史错误为正确。

迁移备份只用于失败恢复，不新增孩子可见的旧课程归档页或另一套历史课程目录。执行记录列出已删除和已修改的路径、原因及校验结果；重复执行无额外删除。检查到并发新作答时重新读取并保留新内容，不能套用过期清理结果。

### 交互与性能要求

按钮只显示孩子的意图，例如“开始互动课”“我的回答：幕”。内部协议与显示文案分离；身份、请求去重及原生消息来源验证必须同步更新并保持旧消息可读。不得只隐藏长文本而继续向模型重复发送完整版本表和两份指令。

每个动作只装载所选任务的目标、需求、相关版本和必要证据。教学内容准备一次并复用，合并可独立的读取及同文件修改；不为时间戳或重复 schema 查询单独增加模型步骤。状态查询、目录浏览、翻页和展示已保存内容不调用模型。不得为缩减延迟取消原回答保存或来源校验。

下面是发布验收目标，不是当前能力或服务承诺。隔离 profile 中使用同一模型和配置，固定资料，分别完成至少十次开始／恢复及十次作答操作；保留中位数、P95、失败次数、模型步骤和请求大小。完整课外部生成时间单独记录，不能从端到端报告中省略。

| 指标 | 首期验收要求 |
| --- | --- |
| 点击与作答回显 | 本机验收 P95 不超过 1 秒；回显不冒充已保存或已评价。 |
| 按钮内部输入 | 不含全工作区版本表，指令只出现一次；固定短回答场景载荷不超过 4 KiB，合法长回答单独测边界。 |
| 首次备课到提交生成 | 固定资料场景中，从点击到首次生成请求发出 P95 不超过 120 秒；外部生成等待另计并完整报告。 |
| 普通作答 | 无恢复异常的固定场景最多 5 个模型步骤；原回答与评价均校验，端到端反馈 P95 不超过 90 秒作为首期上限。 |
| 生成等待 | 任务受理后展示原任务状态；轮询不逐次占用模型推理，不重复提交。 |
| 复用与导航 | 已保存课件可直接打开，翻页和浏览目录产生零次模型调用。 |

90 秒仅是相对当前六分钟作答链路的首期上限，不代表适合长期连续互动。若原生写文件流程仍无法达标，记录具体瓶颈并提出单独架构修订，评估由程序保存确定性状态；不能通过删验收项或把必要工作延后却宣布完成来通过。

### 独立内容审查

生成前保存最多三道完整题目、答案、解析、答案代回后的句子及原材料逐字引文。Host 从原课程的工作区路径读取材料并核对 SHA-256，以当前模型的独立上下文批量审查，不能携带生成者的“通过”结论、会话历史或工具。结构完整且语法、事实、答案唯一性、判分、范围全部明确通过才提交；不确定、超时或缺项保持不可用。

发送给生成服务的需求由 Host 按审定范围、最终教学计划、原材料和唯一题目清单组装，不拼接内部能力总判据、草稿推演或被否决的例句。预审同时检查教学计划与题目清单的一致性；明确只学书面字义的课节不因能力总判据包含读音而增加口头测验。

生成后一次读取实际场景与原题，严格比较已审题干、选项、答案和解析，再独立检查完整内容及六个教学环节。官方生成接口仅接收 requirement，不承诺题目注入或原地修补；服务改写题目时拒绝，不悄悄更新审定版本。已提交计划与预审凭证绑定原任务，修订创建显式替代版本，保留旧题和回答。

审查结果作为受保护的运输凭证保存，按规则版本、模型、原归属、来源、计划及实际内容指纹缓存并合并并发请求。课程 quality 仍由原生 Agent 写入；播放入口独立验证凭证和当前内容，不能凭自填 passed 放行。此凭证不是学习评价或掌握证据。导航、查询、重新打开均不重复推理；审查耗时计入端到端报告。

固定回归集包括“一条水的河流”“游泳需要在水边进行”、正确句子和歧义对照。确定性测试覆盖篡改、遗漏、未知、内容漂移、缓存和重启；真实模型评估单独报告检出与误拒，不能用脚本模型代替。初期规则拒绝后只允许显式修订，不自动反复付费生成。

### 实施顺序

1. 定义单元／课节与既有活动的关联、来源要求、迁移和恢复规则；实现旧无效内容删除与引用修正，在副本验证真实作答保留和重复执行，再覆盖选择语文但旧英语未结束的问题。
2. 同步缩减按钮协议和任务查询，修复所选建议丢失教学需求的问题；保存回答、来源验证、防重复和旧协议兼容一起验证。
3. 接通单节完整互动课的生成、状态展示、打开、恢复、反馈与收尾，再接入复习／补讲小课；先验收一条完整路径。
4. 增加单元目录、按课节生成、单元综合课及教材修订处理；验证跨日、换科和换会话。
5. 在独立 profile 完成真实模型与官方服务验收，再按发布流程更新日常安装。代码与学习数据迁移分别备份；回滚不得丢失升级后新增的真实回答。

## Alternatives considered

**新学默认小课。** 初始准备更轻，但不能满足首次学习先获得完整互动课程的产品要求；小课保留为复习、补讲及用户明确选择的故障替代。

**一次生成整个单元的长课堂。** 能一次取得大量内容，但等待长，难以按课文恢复，也无法利用前面学习的表现调整后续课节；采用单元目录与按需课节。

**每次回答重新生成课堂。** 会重复等待并使内容和题目版本变化；复用课程，只有明确的内容修正才创建替代版本。

**立即让 Host 接管全部业务写入。** 可能减少模型往返，但改变已确认的直接文件架构和来源恢复约定；本期先减少多余步骤，性能未达标时另行评估。

**全部归档旧内容。** 会保留无效课程入口和额外历史目录，不能完成直接清理的要求；对确认无效的内容执行删除与引用修正，保留真实学习证据及必要恢复身份。

## Acceptance criteria

验收同时检查内容、真实操作、持久恢复和性能。合成数据用于自动测试；真实服务与真实 DSH 客户端用于验证集成。新方案不得靠伪造儿童作答或改写日常档案验收，测试身份与日常学习记录隔离。

| ID | 场景 | 必须观察到的结果 |
| --- | --- | --- |
| A1 | 有教材和已确认单元进度，首次开始新课节 | 有单元目录和完整教学需求，恰好提交一次 `openmaic_generate`；不被缺证据改成纯文字摸底。 |
| A2 | 只有知识地图，或缺单元内位置 | 明确待补资料；不虚构教材正文、学校进度或完整单元课，基础目标课需用户明确选择。 |
| A3 | 旧英语暂停后开始语文 | 当前课堂与所选语文需求一致；旧任务可恢复，计划与活动校验通过。 |
| A4 | 生成中双击、刷新、超时、换会话 | 保持同一任务身份；结果未知不再次提交；重启后能恢复。 |
| A5 | 认证拒绝、生成失败或内容核对失败 | 失败原因可见；只提供实际支持的恢复动作，不假装已生成，不自动降级。 |
| A6 | 已完成生成，尚未保存课堂引用时中断 | 从原任务补齐引用，打开原课堂；不产生重复课堂。 |
| A7 | 真实课堂播放和作答返回 | 题面与归属核验通过；原回答保存一次；重复导入无新证据，未知帮助／日期不猜测。 |
| A8 | 观看完成但没有有效回答 | 可记录活动结束，不因观看改变既有能力结论；缺证据时保持未知或待核对，不自动授予掌握。 |
| A9 | 复习答对，或答错后补讲 | 答对且达标可收尾；困难触发针对性小课，后续检验受原额度约束，不重新生成整课。 |
| A10 | 已有“幕”的正确回答 | 复用原回答备课，不重复摸底；仅按新证据更新表现，不把文字选择当朗读证据。 |
| A11 | 学校确认单元结束或用户准备单元测验 | 综合课引用实际材料和证据，标明覆盖缺口；生成、观看与掌握分别展示。 |
| A12 | 教材修订、并发回答、旧档案迁移与回滚演练 | 原题、原回答、原课堂归属保留；冲突可恢复，迁移幂等，升级后回答不丢失。 |
| A13 | 连续操作与性能采样 | 满足前述数值及零调用要求；按钮无内部提示词，报告完整外部生成耗时和失败率。 |
| A14 | 外部课堂不支持精确播放位置或检验额度约束 | 分别显示位置限制或拒绝标记课程可用；不作无依据的恢复和质量承诺。 |
| A15 | 无实际课堂的草稿、废弃空活动及其计划引用 | 删除确认无效的条目和无引用文件，修正当前活动与跨日关联；重载后不恢复废弃任务，校验无悬空引用，重复执行无额外删除。 |
| A16 | 旧内容包含真实回答，或清理时收到新回答 | 原题、原回答与必要来源保持可追溯，评价不被伪改；重新核对并发变化，不能把含回答活动整份删除。 |
| A17 | 旧生成成功日志、可用课堂、暂时认证失败及未知提交混合存在 | 可用且归属核验通过的课堂复用；日志不冒充可用性；暂时无法核验和未知任务保留恢复身份，不按工具调用缺失一律删除。 |

| A18 | 生成前后内容错误、题目改写或伪造通过声明 | 两个已知错误和歧义题被独立审查拦截，正确对照可通过；篡改或缺失凭证不能播放，重复查询不调用模型。 |

## Risks

完整课堂生成依赖外部服务、认证和内容质量；接口存在不代表真实链路可用。官方播放器的进度恢复、生成内容检查及题量约束必须实测，若无法满足，阻止相应能力发布并记录缺口。文字、听力、口语和实际操作证据分别核验。

以完整课优先会增加首次等待与生成成本。通过明确开始才生成、按课节生成和复用已有课程控制开销；不承诺即时完成，不擅自把等待转换为后台批量生成。

原生多文件写入与模型延迟仍可能影响体验。发布前必须实测存档失败恢复及交互耗时；旧内容删除与修改属于升级迁移的实施范围，普通页面读取不得触发；本 spec 的文档交付不代表迁移已执行，也不宣称已完成代码或真实课堂验收。
