# Agent Note: 按科目关联概念与纸上练习

Status: implemented

[English](2026-10-11-student-knowledge-paper-practice.md) | 中文

## 问题

自由文本主题不能稳定关联概念、学习目标、错题和不同日期的练习证据。纸上练习可能在离屏后才上传，不能伪装成正在计时的交互题。直接让模型执行打印命令也无法保证用户看到并确认了要打印的题目。

## 决策

[学习系统决策](2026-10-05-student-learning.zh.md)继续负责课程依据、交互计时和奖励限制。本决策将概念、目标、关系、错题、练习单和纸上结果保存在同一工作区档案。旧集合以空值读取，旧错题的 `topic` 保留原文，关联目标需用户核对。概念由助手提出，家长可修改定义、例子和依据后确认；学习目标只引用同科已确认概念，并使用该科允许的方法。概念关系限同科，因果关系记录方向和资料依据。

练习单只引用已确认且关联同一学习目标的错题，保存逐题答案及依据，学生版 PDF 只展示题目和作答空间。PDF 预览先于本机默认打印队列的确认请求；打印调用由 Host 拥有，模型 shell 不能代替预览和用户确认。队列回执表示已接受任务，不证明纸张输出。打印记录不进入学习奖励。

纸上结果逐题对应已保存的练习单，经照片转录和用户确认后由学习工具保存。纸上结果不要求活动学习段，也不因上传发星；提前练习保留证据，只有已到期且归类未变化的错题才按独立作答更新间隔。可选 SenseVoice Bundle 只把录音转成对话草稿，学生核对后按原生文本作答流程提交；转写不能证明发音。

## 考虑过的替代方案

**继续只用自由文本 `topic`。** 同一目标的不同写法无法稳定汇总，错题与练习单也难以核对来源。

**把纸上结果写成计时学习段内的 `record`。** 上传时间不是纸上完成时间，会误触截止限制并可能产生不真实的参与奖励。

**由模型直接生成文件并调用 shell 打印。** 缺少固定题目版本、预览和明确确认，模型也可能把文件创建误报为已打印。

**在学习面板再建语音录音器。** DSH 的对话麦克风已提供本机 SenseVoice 转写；重复录音与权限处理增加维护面，且转写本身不支持发音评分。

## 验证

状态测试覆盖旧档案读取、同科已确认概念、目标与错题关联、练习单来源、纸上结果和复习间隔。接口测试覆盖真实 PDF 生成以及打印确认前不调用队列；队列调用在测试中替换，不发送真实打印任务。PDF 渲染检查覆盖中文题目和作答线。真实模型的概念质量、图片转录和教学效果仍需人工验证。

## 后果

概念与练习单增加状态体积和模型工具 schema；包携带 Noto Sans SC 字体及许可证。直接打印依赖 Host 的 `lp` 和默认队列，Windows 只提供 PDF 预览。打印回执当前仅显示在界面，不是持久打印历史。科目方法可由工作台和技能查看，但模型给出的定义、关系和答案依据仍需家长核对。
