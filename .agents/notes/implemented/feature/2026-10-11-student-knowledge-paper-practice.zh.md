# Agent Note: 按科目关联概念与纸上练习

Status: implemented

[English](2026-10-11-student-knowledge-paper-practice.md) | 中文

## 问题

自由文本主题不能稳定关联概念、学习目标、错题和不同日期的练习证据。纸上练习可能在离屏后才上传，不能伪装成正在计时的交互题。直接让模型执行打印命令也无法保证用户看到并确认了要打印的题目。

## 决策

[学习决策](2026-10-05-student-learning.zh.md)拥有课程证据与奖励。概念、目标、关系、错题、练习卷和纸面结果在同一工作区学期保留明确身份。旧主题不变，直到有人核对并关联。导师提出概念；家长可修改定义、示例和来源后确认。目标和关系限于同科，使用科目方法，明确因果方向／依据。

练习卷冻结题目、来源与目标，保留原始答案和评分。学生卷只含题目和作答空间；[HTML 练习卷决策](../simplification/2026-10-25-student-worksheet-html.zh.md)拥有共享浏览器渲染、预览和打印对话框。已保存文件或打印对话框不能证明物理输出。打印不发学习奖励。

agent 在转录和明确家长核对后将确认纸面答案保存在正式练习卷文件。纸面学习不需活动学习块，上传不发星。家长确认的实际日期和已知帮助决定独立复习，包括[复习放宽](2026-10-16-student-review-relaxation.zh.md)的提前推进。[原生学习架构](../architecture/2026-11-12-student-learning-flow-architecture.zh.md)拥有稳定关联与旧版未知事实。可选 SenseVoice 将文字插入原生草稿供发送前核对；转写不建立发音证据。

## 考虑过的替代方案

**继续只用自由文本 `topic`。** 同一目标的不同写法无法稳定汇总，错题与练习单也难以核对来源。

**把纸上结果写成计时学习段内的 `record`。** 上传时间不是纸上完成时间，会误触截止限制并可能产生不真实的参与奖励。

**由模型直接生成文件并调用 shell 打印。** 缺少固定题目版本、预览和明确确认，模型也可能把文件创建误报为已打印。

**在学习面板再建语音录音器。** DSH 的对话麦克风已提供本机 SenseVoice 转写；重复录音与权限处理增加维护面，且转写本身不支持发音评分。

## 验证

学习和正式文件测试覆盖科目关联、冻结练习卷来源、纸面作答保留和独立日期复习。客户端练习卷测试覆盖共享题图、作答空间和预览；确定性渲染不是物理打印证据。真实模型概念质量、转录和教学效果仍未测量。

## 后果

结构化记录让纸面与屏幕学习共享证据，不把上传时间当作作答时间。浏览器拥有打印，不依赖 Host PDF、系统队列或随包 PDF 字体。家长仍需核对概念定义、关系、转录与答案依据；未知事实不进入已验证日期指标。
