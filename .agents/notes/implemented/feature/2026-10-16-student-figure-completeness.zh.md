# Agent Note: 一二年级图形补全与简笔画兜底

Status: implemented

[English](2026-10-16-student-figure-completeness.md) | 中文

## 问题

第十种图形（[重叠圈](2026-10-16-student-overlap-figure.zh.md)）只补上了一个缺口。把一二年级四份数学地图整个核对一遍后发现更多：数的分与合、规律条、数墙、方格表（幻方、座位图、数位表）、点子方阵、平面与立体图形、计数器、厘米尺、方向板、天平、田字格和四线格都没有对应图形，钟面也只画整时和半时。每缺一种，题目就只能绕道文字，或者「看图」题没有图，或者再等一次按需补图形。

## 决策

词汇表扩到二十三种：`split`、`sequence`、`wall`、`grid`、`dot-array`、`plane`、`solid`、`counter`、`measure`、`compass`、`balance`、`writing` 与原来十种并列，`clock` 的分钟扩到 5 的倍数（0–55，带校验，分针不会落在刻度之间）。每种都有严格 schema 和已保存题目／浏览器练习卷共享 SVG 渲染；[HTML 练习卷决策](../simplification/2026-10-25-student-worksheet-html.zh.md)拥有预览和打印。最后一种是 `sketch`：有限画布（高度 40–260）里最多 24 笔（`line`、`arrow`、`polyline`、`rect`、`circle`、`text`），坐标 x 用 0–480，校验笔画不越出画布。出题参考列全清单并要求优先用专用图形；练习卷提示词和技能文档改成指向这份清单，不再各自维护图形列表。

## 考虑过的替代方案

**继续按需加图形。** 每碰到一个新主题就要停一次；地图本身就是清单，一次补齐比再打断几次便宜。

**开放渲染：让模型写 SVG 或绘图代码。** 作为可打印卷的载体已被否决（没有记录、没有批改路径），这次同样不选：手写图形风格飘、高度不可预测，还要给打印链路引入消毒层和 SVG 依赖。

**一个通用的万能图形。** 那会把可读的词汇表换成到处都在用的小型绘图语言；专用图形让常见题型保持教材样式、可校验，`sketch` 只覆盖长尾。

## 验证

Schema 和 CLI 资源测试验证全部 23 种，拒绝无效钟面、数墙和越界简笔画。客户端练习卷测试通过共享 SVG 渲染完整题图集。最初教材目视检查指导天平标签、五分钟指针和写字示例；这些不能证明当前真实模型绘图质量或物理打印。

## 后果

一二年级地图上要用的图形现在都能画；长尾也不再堵住出卷，未覆盖的图形降级为受限的简笔画而不是文字替代。质量不均是有意的：专用图形保持教材样式，简笔画由模型现场拼、可能粗糙。
