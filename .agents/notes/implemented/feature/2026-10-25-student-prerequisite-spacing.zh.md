# Agent Note: 教学沿前置链下钻与错因感知的复习间隔

Status: implemented

[English](2026-10-25-student-prerequisite-spacing.md) | 中文

## Problem

教学建议完全不看依赖：`curriculumView` 已为展示算了前置关系的拓扑序，但「需要教学」的目标判定与建议选择从不使用它——孩子在表内乘法卡住时，系统会反复在乘法口诀上出题，即使真实缺口是更早的乘法意义。复习间隔同样一刀切：确认后答错、半对或依赖帮助一律回到第二天，第一次失误与反复答错待遇相同；同一目标上同错因复发的错题，巩固卷仍按最低档「换数字」出变式。

## Decision

教学沿前置链下钻：`studyInsight` 对每个需要教学的目标沿同科前置边（概念级 prerequisite 关系、经目标的概念归属映射到目标）广度优先上溯，返回最近的一个未掌握且未到期目标；命中时该前置目标获得 `prerequisite-gap` 理由与优先级加权，建议重定向到它并携带 `redirectedFrom`（原目标），工作台建议卡显示「补好这个目标后再学原目标」。前置掌握后建议自动回到原目标。

复习间隔错因感知：同一错题确认后第一次答错/半对回到第二天，再次答错则隔两天；`reviewPlan` 对同目标存在两条及以上共享错因的活跃错题时，把变式下限从「换数字」提到「换情境」。间隔与变式的判定都由已有作答与错题证据推导，不改状态文件。

## Alternatives considered

**按拓扑序找「最靠前」而非「最近」的缺口。** 长链上最靠前的目标可能早已因别的证据在练；最近的未掌握前置更贴近当前卡点，也是教师会先核对的一步。

**按单题错因匹配复发。** 作答证据不携带错因（错因挂在错题与批改上），逐题配对无数据支撑；以「同目标同错因的活跃错题数」度量复发即可满足变式升级的需要。

## Consequences

建议顺序新增 `prerequisite-gap` 一档（位于到期错题之后、直接教学之前），前置目标补完自动回落；复习排期对反复答错更保守，巩固卷对复发错因先换情境。三科 347 条前置关系全部可用，跨年级范围不受影响。学习顺序与建议规则仍归[知识地图决策](../feature/2026-10-12-student-knowledge-map.zh.md)；仓库与真实 DSH 验证归 [HANDOFF.md](../../../../HANDOFF.md) 所有。
