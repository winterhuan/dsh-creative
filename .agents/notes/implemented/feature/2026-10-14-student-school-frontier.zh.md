# Agent Note: 学校进度界线

Status: implemented

[English](2026-10-14-student-school-frontier.md) | 中文

## Problem

学生一边上学一边在家里练，整册知识地图会把学校还没教到的单元也排进今天的新课和摸底。家长确认的课程只保存一段单元文字，这段文字不限制摸底、薄弱点和下一个新目标。摸底抽到没教过的目标时，一次答错就会把它标成需要加强。

## Decision

某科教材确认之后，`school-progress` 保存学校教到的内置地图单元、确认时间、跟进方式（`keep-up` 跟上学校或 `catch-up` 先补缺）、是否预习下一单元，以及进度（`teaching` 教学或 `review` 复习周）。确认时间由宿主写入。单元 id 必须属于档案上的年级和学期。用 `course` 或 `configure-course` 更换教材时保留这条记录。

某科还没有这条记录时，该科的建议仍覆盖整册。有记录之后：

- 到期错题和薄弱点只有落在当前单元或更早的单元时才排在前面。没有学习目标的错题仍进入队列。挂在更后单元上的错题留在错题本里。
- 摸底取样和覆盖率的分母只用这些已教单元。
- `keep-up` 只在当前单元出新课。`catch-up` 在已教单元里取第一个还没开始的目标。`review` 不开始新目标。
- 教学周打开预习时，已教范围内没有新课之后，才建议下一单元的第一个未开始目标，这个目标不进入摸底。建议种类是 `preview`。
- 后面的单元仍有未开始的目标，且上面都没有可做的事时，建议种类是 `hold`。

工作台可以让家长确认还在这一单元、进入下一地图单元，或标成复习周。家里练熟不会把界线往前移。

## Alternatives considered

**按日期或家里的掌握程度自动前移。** 教师会停、会复习、会调整顺序。把家里练熟的单元当成学校已经教完，会因为提前练习而开始下一章。

**让作业照片直接改单元。** 照片可以支持一句提议。未经家长确认就保存，会把猜测写成学校进度。

**在地图上藏起后面的单元。** 家长仍然需要看到这一册的其余部分。地图保留这些单元并标明学校还没教到；它们退出今日建议和摸底。

## Consequences

没有确认界线的科目仍按整册走，已有档案要等家长标出单元后才改变。此后摸底覆盖率表示“学校已经教到的部分”，不是整册。预习中的练习仍可能形成薄弱点；这个薄弱点不排在已教目标前面。课程上的单元文字仍是家长对课本的标注；计划使用的是地图单元 id。见[知识地图](2026-10-12-student-knowledge-map.zh.md)。
