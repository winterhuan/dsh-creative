# Agent Note: 学生学习插件全面改造（取消时长限制）

Status: implemented

[English](2026-10-30-student-overhaul.md) | 中文

## 问题

在软拒绝取消之后，建议单段、休息与每日时长仍占据档案表单、工作台文案和状态载荷。家长还要手填确认语，学习段进行中不能改档案或课程，也不能一键切科或结束本段。包内已有概念库与知识点事实，但没有按学习目标校验的习题知识库，摸底、西蒙四步与每日小卷只能依赖模型自由出题。复习间隔仍是 3 / 7 / 14 / 30，二年级下册地图的可考事实也不够密。

## 决策

从档案、学习段、作答和状态中移除全部时长与休息字段。迁移旧 `.study/state.json` 时剥离 `profile.limits`、`breakUntil`、`sessions[*].deadline` 与 `attempts[*].late`。阶段只有 `ready` 与 `studying`；状态只保留安静的已学时长（`blockElapsed`、`todayElapsed`）与周报。`start` 自动收束未结束学习段；`task` 可替换未作答题目；学习段内仍可切科。

内置经校验的习题知识库 `knowledge/curriculum/exercises/{chinese,math,english}.json`，由 `curriculum.ts` 加载；`kind=elements`、`kind=diagnose`、`kind=review-sheet` 附带匹配母题，新增 `kind=exercises`；工作区 `exercises` 集合配合 `save-exercise` / `delete-exercise`。间隔复习为 1 / 7 / 16 / 35 天；已掌握复测为 35 天。任务可带微步骤；今日页展示西蒙四阶段、目标动作、费曼「当小老师」与探究疑问输入。知识地图渲染单元 → 知识点 → 关系逻辑树并着色掌握状态。家长设置可就地更新档案；面板确认语默认填充；课程、进度、兴趣与错题确认在学习段进行中也可提交；错题本可直接增删改已确认错题。二年级下册语数英地图补齐更密的 facts、examples 与 questionPoints。

本笔记拥有取消时长限制、习题知识库、1 / 7 / 16 / 35 曲线以及上述家长/学生流转改动。[软提醒笔记](../bug-fix/2026-10-18-student-soft-time.zh.md)继续拥有作答匹配、选项归一与摸底强度；其中的时长字段已删除。[复习放宽笔记](../feature/2026-10-16-student-review-relaxation.zh.md)继续拥有提前推进与不降阶；已巩固间隔现为 35 天。

## 备选方案

**保留无拒绝的软建议。** 倒计时与休息钟仍暗示硬停，与孩子先前被拒绝的体验冲突。删除字段才能结束矛盾。

**习题只存在于对话草稿。** 摸底与西蒙四步就没有与目标绑定、经校验的题干与配图。

**保留 3 / 7 / 14 / 30。** 产品方案选定二年级复习用 1 / 7 / 16 / 35 遗忘曲线。

## 验证

学生包测试覆盖迁移、学习段中开新段、习题加载与查询、1 / 7 / 16 / 35 调度、微步骤、无时长文案的工作台、思维导图选择以及错题/习题面板操作。本改动需通过根目录 `typecheck`、`build`、`doc-sync` 与 `hygiene`。本轮未在真实 DSH 浏览器跑通。

## 后果

既有工作区加载时不再保留时长字段。辅导者不再收到 `timeNotice` 或 late 标记。习题库 ID 与工作区真题成为练习单与变式的持久引用。已巩固错题按 35 天间隔。家长可在学习段中改设置；孩子结束本段时不必填休息计时。
