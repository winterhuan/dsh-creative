# Agent Note: 小说创作模式

Status: implemented

[English](2026-10-06-story-mode.md) | 中文

## 问题

安装小说包后，写作能力和工作台的出现与会话用途无关。作者需要明确的小说模式，让工具和工作台跟随所选会话，同时保留草稿。

## 决策

现有包声明 `story` Agent preset，不改变新任务默认值。作用域内的 `/agent` 入口负责小说技能、生产工具和写作钩子。简短的小说协作者身份区分讨论、审稿和已授权写作；详细方法保留在六个按需技能中。原生文件系统、Shell、搜索、作业、委派和工作流工具支持这些技能。压缩和工作流服务分别使用隔离组。

Host 入口保留文件 API 和凭据设置，避免保留多个预设代际时重复注册路由。浏览器读取会话的 `agentPreset` 投影，包括空白会话创建后的选择。只有小说会话显示工作台入口并接管小说文件跳转。投影未知时编辑器隐藏，已知其他预设拥有会话时关闭恢复的小说标签页。全局设置保持可用。

编辑缓冲沿用 `creative.story.v1`；切换会话或隐藏入口不清空其状态。已有对话保留原预设，可在新小说会话接续同一本书。已有非小说会话的草稿仍保留存储，但没有小说工作台入口。不迁移对话历史或作品文件。

[创作工作台决策](2026-09-03-creative-workbench.zh.md)继续负责文件、草稿和生产归属。[四领域决策](../architecture/2026-09-30-creative-four-domain-plugins.zh.md)继续负责独立分发。本决策只改变小说启用边界；两份记录保持活跃并互相链接。规则归属和原生工作流决策继续负责任务顺序与章节事务的理由。

## 考虑过的替代方案

**工作台永久显示：**让安装等同于进入小说环境，并在无关会话中显示。

**把完整插件移入预设：**混合会话作用域工具与 Host 路由、设置，可能在保留多个预设代际时重复注册路由。

**重写编辑器和存储：**增加迁移却无益于模式选择；已有会话缓冲和带版本的文件保存已经负责数据。

## 影响

小说行为和入口跟随会话用途。预设显式列出工具，升级 DSH 时须核对组合。全局侧栏注册需要同时订阅所选会话身份和会话投影更新；入口显示变化时，标签页主体和编辑器存储保持注册。预设不是文件系统安全沙箱，机械检查不评价文学质量。

## 验证

预设测试覆盖原生注册表挂载、子会话组合、工具和技能隔离、作用域写入钩子及身份提示快照。客户端测试覆盖未知模式、空白会话变更、会话切换、观察器释放和按目标会话判断文件接管。已有原生章节测试覆盖准备、独立审稿和带保护的提交。

类型检查和构建通过。默认并发全量测试报告一项章节工作流超过 30 秒、754 项通过；工作流文件独立运行通过，四个 worker 的全量运行通过全部 755 项。不限制宿主并发时的超时仍是验证限制；未放宽测试超时或断言。文档和规范检查通过。

隔离 DSH profile 与 Chrome 验证了模式选择、小说会话专属工作台、跨会话和刷新后的文件选择及未保存草稿恢复，以及窄窗口布局，无页面脚本错误。浏览器证据位于 `/tmp/dsh-story-mode.RrT7Cf/`。未调用真实模型或付费检测；这些检查验证组合和 UI 行为，不认证自主文学创作表现。
