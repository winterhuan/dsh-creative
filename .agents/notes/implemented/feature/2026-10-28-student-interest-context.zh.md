# Agent Note: 兴趣标签套练习场景，到期复习只留短清单

Status: implemented

[English](2026-10-28-student-interest-context.md) | 中文

## Problem

整份到期错题曾经是唯一的每日建议，孩子到不了当前的校内目标。题目场景也与孩子喜欢的事无关，同一个知识地图事实进不了孩子愿意进入的情境。

## Decision

学期设置保留家长兴趣标签。缺少标签时使用既有六个示例；`study_status` 提供它们和按上海日期轮换的 `interestFocus`。题目、变式、每日环节与 OpenMAIC 要求可使用这些场景，可考事实仍是知识地图事实。

在所选学科内，建议先教需要教学的目标，再加强薄弱点，再提供到期摸底，最后学新目标。最多两条到期错题伴随建议。未完成学习是主要继续入口：浏览其他学科或教材不替换当前题目，明确选定目标优先于其他建议。[原生学习架构](../architecture/2026-11-12-student-learning-flow-architecture.zh.md)拥有范围、原生意图和已保存证据。相关就绪课程可伴随当前目标；生成留在 [OpenMAIC 归属](2026-10-28-student-openmaic-lessons.zh.md)的 shell。没有时长限制。

## Alternatives considered

**另写 `.study/interests.json`。** 课表那样写，是因为生成不能抬学习修订号。标签是家长设置，属于学期设置并出现在 `study_status`。

**仍把全部到期错题排在任何新内容前面。** 这是原来的顺序。几十条过期错题会一直挡住校内单元。

**让兴趣标签变成可考事实。** 孩子喜欢的场景不是课本事实。答案仍必须对上 `facts`。

## Consequences

没写这个字段的旧档案在家长保存前仍显示示例标签。一个目标若有多条未完成错题、反复最近出错，或需要教学，仍可以成为练习目标。单独一条到期错题不行。Host 仍不调用 3000 端口。这次没有真实的 DSH 浏览器验证，也没有调用正在运行的 OpenMAIC。
