# Agent Note: 兴趣标签套练习场景，到期复习只留短清单

Status: implemented

[English](2026-10-28-student-interest-context.md) | 中文

## Problem

整份到期错题曾经是唯一的每日建议，孩子到不了当前的校内目标。题目场景也与孩子喜欢的事无关，同一个知识地图事实进不了孩子愿意进入的情境。

## Decision

家长设置把 3 到 8 个兴趣标签存在学习档案上。字段空着时，状态读这六个示例：购物超市钱、运动球类、动物宠物、故事角色动画、积木拼搭手工、美食做饭。`study_status` 返回这些标签和 `interestFocus`（按上海日期从列表里轮换）。出题、情境变式、每日环节和 OpenMAIC 的 requirement 用其中一个标签套场景，可以换标签。事实仍只核知识地图的 `facts`。主建议先教需要教学的目标，再练一个薄弱原因不只是单条到期错题的目标，再做到期摸底，再学新目标。`dueToday` 最多 2 条，`dueBacklog` 是全部到期数。今日页在这条建议旁提供趣味情境练习和开互动课。课已生成时，「去上课」置顶。生成仍走[互动课](2026-10-28-student-openmaic-lessons.zh.md)里的助手 shell。软时长仍只提醒。[知识地图](2026-10-12-student-knowledge-map.zh.md)笔记里的建议顺序与这里一致。

## Alternatives considered

**另写 `.study/interests.json`。** 课表那样写，是因为生成不能抬学习修订号。标签是家长设置，和时间限制一样，放在档案里并出现在 `study_status`。

**仍把全部到期错题排在任何新内容前面。** 这是原来的顺序。几十条过期错题会一直挡住校内单元。

**让兴趣标签变成可考事实。** 孩子喜欢的场景不是课本事实。答案仍必须对上 `facts`。

## Consequences

没写这个字段的旧档案在家长保存前仍显示示例标签。一个目标若有多条未完成错题、反复最近出错，或需要教学，仍可以成为练习目标。单独一条到期错题不行。Host 仍不调用 3000 端口。这次没有真实的 DSH 浏览器验证，也没有调用正在运行的 OpenMAIC。
