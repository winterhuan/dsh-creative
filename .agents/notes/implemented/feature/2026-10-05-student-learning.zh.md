# Agent Note: 使用已确认课程资料的学生学习系统

Status: implemented

[English](2026-10-05-student-learning.md) | 中文

## 问题

低龄学生需要简短、有鼓励的练习，并在跨对话时保留错题和学习证据。地区与年级无法确定学校的教材版次。虚构教材内容或按挂机时长奖励会损害学习效果。

## 决策

在 `packages/education/student` 提供独立安装的 `@winterhuan/dsh-student`。交互式原生侧栏开始和结束学习、接收答案与照片、展示进度并收集家长确认的设置。原生 DSH 技能引导语文、数学和英语学习，工具在每个工作区保留一名学生一学期的记录。首份教学参考面向上海二年级上册。家长确认学年、各科教材和当前单元；课程尚未确认时仍可进行通用基础练习。

课程记录保留来源身份、版次、适用范围、位置和用户确认。家长通过官方入口查阅或提供所需课页；插件不下载或再分发教材。图片录入使用 DSH 视觉能力，识别不确定之处必须修正后才能安排复习。

代码限制单次和每日学习时长，要求下一段学习前先休息，每天最多按实际作答和复述发放两颗星。时长限制覆盖所有学科和探究学习。间隔复习要求不同日期的独立作答，提示后的答对不能证明掌握。题目、已提交答案与提示请求在刷新后保留，评分必须对应已保存题目，请求过提示不能记为独立作答。本地侧栏接口解析主会话，修改前检查界面显示的修订号，不接受评分或奖励命令。状态修改使用当前会话的文件系统，并按版本条件替换。

## 考虑过的替代方案

**只用提示词保存记录和限制时长。** 实现更少，但无法可靠阻止重复奖励、并发覆盖或休息期间立即重开。

**内置教材库和独立辅导应用。** 尚未核实学校教材就引入版次维护和分发责任。原生 DSH 对话、图片和文件已经能够承担所需交互。

## 验证

- 原生工具测试覆盖设置、来源确认、日常作答、转录记录和复习；独立构建与隔离配置安装成功。
- 测试拒绝课程不匹配、不确定转录、重复奖励、提前复习、跳过休息和过期写入；重新读取能恢复已存进度。
- 来源说明记录官方入口和未解决的版次匹配，不虚构内容或下载教材。
- 隔离 DSH 配置的浏览器检查覆盖设置、教材确认、计时学习、保存回答与提示、反馈恢复、休息、星星、转录修正、图片接收、深浅色和窄窗口。题目与评分使用脚本化测试数据，没有页面脚本错误。
- 尚未测量真实模型的转录准确率与教学效果。

## 后果

插件无法认证家长身份、测量注意力或保证生成答案正确。它记录明确确认和可观察的作答；辅导时核对答案依据，存疑时停止判分。模型可能忽略工具指引，因此计时约束针对记录的学习流程，不能表述为操作系统级屏幕锁。
