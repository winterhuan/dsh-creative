# Agent Note: 使用已确认课程资料的学生学习系统

Status: implemented

[English](2026-10-05-student-learning.md) | 中文

## 问题

低龄学生需要简短、有鼓励的练习，并在跨对话时保留错题和学习证据。地区与年级无法确定学校的教材版次。虚构教材内容或按挂机时长奖励会损害学习效果。

## 决策

[领域模式决策](../../archived/feature/2026-10-06-domain-modes.md)拥有激活边界。独立安装的 `@winterhuan/dsh-student` 提供语文、数学与英语原生 DSH 指导，每个工作区保留一名学生的一学期。[原生学习架构](../architecture/2026-11-12-student-learning-flow-architecture.zh.md)拥有对话操作、正式文件、稳定题目／作答身份、已验证证据及补充受保护手动保存。

课程记录保留来源身份、版次、范围、位置和明确家长确认。家长使用官方入口或提供相关课页确认学校匹配。对齐尚待完成时仍可做通用基础练习。[默认教材决策](2026-10-10-student-default-textbooks.zh.md)拥有随包基础材料；插件不下载教材。图片转录不确定时需修正后才能安排复习。

没有学习块、休息或每日时长限制；[全面改造决策](2026-10-30-student-overhaul.zh.md)拥有此政策。每日最多两颗星奖励已记录参与和复述。独立且有日期的作答建立间隔复习；提示后或未验证的答案不能证明独立。评分必须先有原始作答，刷新后仍保留。原生和 shell 写入不受应用版本保护；独立验证和已观察备份不能保证恢复未观察覆盖。

## 考虑过的替代方案

**只用提示词保存记录和限制时长。** 实现更少，但无法可靠阻止重复奖励或并发覆盖。已验证事实保留这些规则；[全面改造决策](2026-10-30-student-overhaul.zh.md)记录没有时长限制的理由。

**完整的校内教材库和独立辅导应用。** 尚未核实学校教材就引入版次维护和分发责任。两本范围明确的基础练习默认教材由独立教材决策规定，不据此建立校内关联。原生 DSH 对话、图片和文件已经能够承担所需交互。

## 验证

- 原生工具和正式文件测试覆盖设置、课程确认、已保存答案、帮助、复习、陈旧手动保存及重复奖励。
- 来源指导指出官方入口和未解决版次，不虚构内容或下载教材。
- 确定性集成使用真实原生工具与独立文件消费方；发布浏览器／安装检查归 [HANDOFF](../../../../HANDOFF.md) 所有。
- 真实模型转录准确率与教学效果仍未测量。

## 后果

插件不能认证家长、测量注意力或保证生成答案。它记录明确确认与已观察学习；不确定事实保持可见。模型可能忽略指导。安静显示的已用时长按上海日历日期计算，不锁屏或拒绝迟到作答。
