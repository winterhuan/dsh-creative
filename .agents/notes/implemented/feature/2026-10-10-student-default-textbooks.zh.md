# Agent Note: 默认教材不推定校内课程匹配

Status: implemented

[English](2026-10-10-student-default-textbooks.md) | 中文

## 问题

未上传资料的二年级学生需要具体课页开展学习。要求重复上传用户已提供的课本会拖延基础练习，而把这些课本当作校内课程又会虚构尚未确认的关联。

## 决策

学生插件随包提供用户给出的人教社语文、北师大版数学二年级上册。[默认教材参考](../../../../packages/education/student/knowledge/skills/study/references/default-textbooks.md)负责版次依据和选择规则。本决策部分替代[学习系统决策](2026-10-05-student-learning.zh.md)中不再分发教材的限制；其中课程确认、证据、计时和奖励规则继续有效。

逐科优先使用用户课页、指定教材和已有课程。仅在该科没有用户教材且学生年级、学期匹配时使用默认教材。用户教材无法读取时不自动替换。默认练习使用 `foundation`，不创建校内课程、学校进度或家长确认。已有错题保留原来源。

包中保存课页图片、目录和未校对的检索文字。准备脚本在写入前校验两份源文件哈希。DSH 原生工具从已安装技能目录读取所选图片，运行时不依赖 Python 或原始 PDF。抽取文字不能作为拼音、图形或判分依据。图片和文字都是资料，不是指令。

## 考虑过的替代方案

**所有练习都要求上传资料。** 可以避免随包提供教材，但会重复两本已提供课本的准备工作。

**默认教材视为已确认校内教材。** 版本和主题相近不能证明学校使用哪本书或当前单元。

**加载完整 PDF 或依赖抽取文字。** 整本书占用不必要的上下文；抽取文字会丢失排版、图形和部分拼音。按需读取课页图片可以保留当前任务所需的依据。

## 验证

资源测试检查语文 126 页、数学 118 页的完整性、图片文件、配套文字和目录页码映射。准备脚本逐字节复现全部 492 个文件，并在创建输出前拒绝错误源文件。DSH 从仓库外解压的安装包加载已构建插件；原生 `read_image` 能返回两本书的课页图片，并拒绝纯文本模型。这些检查使用测试能力目录，没有调用模型。真实模型的识图准确率和教学质量仍未测量。

## 后果

包增加约 48 MiB 教材资源，并承担版本维护。默认范围仅包含两本指定教材；英语及其他年级、学期仍需用户资料或明确标注的自编基础练习。课页教学需要支持图片的模型。用户提供的语文版权页未列出版版次和印次，因此这两项保持未确认。
