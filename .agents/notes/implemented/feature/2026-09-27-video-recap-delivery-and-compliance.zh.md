# Agent Note: 视频解说区分可执行交付证据与发布批准

Status: implemented

[English](2026-09-27-video-recap-delivery-and-compliance.md) | 中文

## 问题

后台媒体作业可能超过前台执行器时限。进程环境检查看不到已配置的凭据引用；延后截短文本还可能让交付必然拒绝的语音重复计费。缺少转录不能证明剪点安全，无密钥降级也不能被当作正式成片。

## 决策

后台生产将 shell 执行器设为不因前台时限过期，取消和脚本自身超时仍负责终止。预检使用与执行相同的凭据/profile 视图。Fish 使用真实的 `fish-audio` 标识，音色 ID、Token Plan 集群和音乐路径进入 profile 设置；高级合成选项仍是脚本环境设置。

语音在付费前检查文本时长预算。实际生成仍超时的段落返回改写，不截词、不自动二次合成。共享 Provider 调用在请求前拒绝缺少凭据。原句剪点检查要求转录或明确的创作者豁免。

交付证据测量实际旁白覆盖、连续原片画面、没有旁白覆盖的原片区间、声明的授权依据和画幅/竖屏处理。度量不验证授权合法性，也不保证平台接受。

显式 `--draft` 路径可用已安装的本地 Whisper 模型、提供的转录或记录的豁免；有限的分镜样帧由 Agent 写观察。渲染使用本地语音或显式选择的时序占位音，附可开关字幕轨。`draft_status.json` 记录降级及 `release_ready:false`，Studio 标记本地草稿。Doctor 报告本地能力，不隐式下载模型或调用付费服务。

单一 runtime 目录维护公共 Python 配置、Provider 客户端和重复的写作辅助代码。构建将代码复制到可独立分发的 Skill 树，测试拒绝副本字节漂移。合成素材测试无需 Provider 即可覆盖草稿、短剧合成、流验证、字幕和抽样复核。

## 考虑过的替代方案

仅加大前台超时不能提供后台作业所需的生命周期。拒绝把缺少 ASR 视为允许断句，因为这会抹去证据缺口。本地预览保留草稿性质，授权声明保留为创作者陈述，不推断已经获准。

## 验证

无密钥合成素材运行产出可解码且带视频、音频和字幕的草稿。测试覆盖合成前拒绝、转录豁免、交付度量和运行时副本字节一致性。真实 DSH 检查覆盖草稿播放、未验证标识及两种主题。这些离线检查未调用付费提供方或本地 Whisper。[工作台决策](2026-09-03-creative-workbench.zh.md) 继续拥有 Session、权限、凭据和作业职责。

## 影响

本地 Whisper 仍需已安装模型。分镜观察和时序占位音存在明确质量限制。烧录字幕需要 libass，可开关字幕轨不需要。本决策负责执行与交付，不定义解说吸引力的创作标准。
