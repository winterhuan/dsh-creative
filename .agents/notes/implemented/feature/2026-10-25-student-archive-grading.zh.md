# Agent Note: 批量抽查批改、派生字段出文件与学期归档

Status: implemented

[English](2026-10-25-student-archive-grading.md) | 中文

## Problem

纸面闭环的家长摩擦足以让主通道荒废：照片转录后必须逐题核对才入库。复习派生字段（stage、independentDays、dueAt）每次读取都从证据重放，却仍写回状态文件——双份真相加写放大。学期结束只有「换工作区」一条路，证据留在原文件里没有归档出口。

## Decision

家长可抽查确认高置信、答对、帮助已知且无疑点的一批转录；低置信、错误、部分正确、未判定或帮助未知条目仍需逐项核对。置信度不能提供正确性或独立性。原生聊天承载默认确认意图，补充手动表单使用相同验证器。

派生复习阶段、独立日期和到期日不进入持久集合事实。共享证据读取回放提供它们，保留单一真源。旧版派生字段可读，不改变字节。

家长确认的归档在替换活动设置前保留原学期正式实体。agent 以相同身份检查并恢复已有有效输出；归档／导出与活动替换分别写入，明确返回部分结果。新设置创建新学期身份。[原生学习架构](../architecture/2026-11-12-student-learning-flow-architecture.zh.md)拥有字节验证迁移、恢复、旧学期拒绝和并发限制。

## Alternatives considered

**模型自动入库高置信题。** 把「未经家长动作不入库」改成模型裁量，超出本包的信任边界；批量确认保留家长把关。

**归档即删除状态文件。** 文件系统服务未必提供删除；带 `archivedAt` 的最小文件达到同样的「读作不存在」，且 schema 显式可见。

## Consequences

家长核对使用一批符合资格条目加逐项检查；派生证据有单一归属。持久学期导出保留原身份，中断操作可检查并恢复。真实家庭批量／归档操作与确定性回归证据分开。[练习卷笔记](../simplification/2026-10-25-student-worksheet-html.zh.md)和[读路径笔记](../simplification/2026-10-25-student-read-path.zh.md)保留渲染与回放理由；发布检查归 [HANDOFF](../../../../HANDOFF.md) 所有。
