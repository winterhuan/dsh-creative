# Agent Note: 短剧交付统一合成与生产证据

Status: implemented

[English](2026-09-27-short-drama-finished-episode.md) | 中文

## 问题

独立读取文档和按文件名关联媒体，会把混合版本投射为同一剧集，或把输出挂错镜头。只检查容器签名会接受不可播放文件；先消费确认再发现缺少凭据，会在请求尚未发出时浪费确认。只生成镜头也无法交付对白、音乐和字幕。

## 决策

现有 drama 入口接受 `episode-compose`。确认后的来源计划固定片段顺序与裁剪、从剧本提取的定时对白、可选音乐、尺寸，以及保留或替换视频模型原声的明确选择。适配器复用 video-recap 的语音、混音、音乐压低、响度和字幕代码，发布一份可解码且带可开关字幕轨的剧集；可选字幕烧录需要 libass。新增配音费用继续走现有预览、确认和账本。

参考标签保留为任意语言的创作者文本。Provider 提示只接收图片位置 token 和目标语言用途，不接收标签或控制范围。Python 创作文档检查器将身份、造型和地点参考与镜头声明主体对照，支持待补参考的关键帧准备、分镜起始帧及视频/音频后缀。最终视频准备在投产前执行该检查。

运行器在消费确认前发现缺少凭据；请求开始后发生失败仍消费确认。暂存输出必须有可用流、符合声明的时长/尺寸/音频，并成功解码后才发布。带上下文的成功运行发布目标、请求、框架作业身份和媒体哈希清单。Client 通过清单关联当前仍匹配的字节，文件名不建立归属。

整集端点一次读取五份文档，用这些字节执行 Python 结构检查，并复核版本；并发改动返回冲突。Client 保留未保存文本，版本不一致或未保存时阻止投产。Python 拥有结构诊断，TypeScript 投影展示项，只接受显式有效的 VISUAL ID；共享样例覆盖两端。错误在单项、批量和合成进入提交前阻断，警告不阻断。

媒体复核每条 clip 采三帧并生成联系表，可在明确确认付费后调用共享图片分析 Provider。身份、地点及画面文字观察保留为建议。

## 考虑过的替代方案

拒绝自由拼装 shell 合成，因为它丢失确认计划与凭据链路。拒绝文件名推断和两套独立结构验证，因为重命名或解析漂移会改变生产含义。媒体复核保留建议性质，因为抽样不能证明整条 clip 连续性。

## 验证

合成素材测试按顺序组合片段、替身对白、音乐和可开关字幕，随后解码结果并抽帧复核。契约测试验证缺少凭据时保留确认，并拒绝无效媒体。快照测试检测文档缺失及文档或项目配置的并发变更；真实 DSH 浏览器在磁盘冲突时保留未保存文字，并阻断无效的生产准备。[工作台决策](2026-09-03-creative-workbench.zh.md) 继续拥有 Session、权限、凭据和作业职责。

## 影响

合成需要 ffmpeg/ffprobe 与语音凭据，计划和参考仍受生产运行器大小限制。没有清单的旧输出保留为文件，不作为目标的已跟踪版本。
