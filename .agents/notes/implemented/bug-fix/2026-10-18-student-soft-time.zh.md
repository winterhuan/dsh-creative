# Agent Note: 学习时长改为软提醒

Status: implemented

[English](2026-10-18-student-soft-time.md) | 中文

## 问题

2026-10-18 的一次二年级学习停住了：建议时长被当成拒绝，后面的校验又拒绝了孩子已经给出的回答。

- 超过本段建议后，作答和反馈被拒绝。
- 休息未结束会拒绝下一段；当天建议快用完时，下一段被缩短。已记录 18/20 分钟时，新的数学段只有两分钟。
- 答案已经保存后，反馈失败，错误没有指出哪个字段不一致。
- 选择题必须与公布的选项逐字相同，因此 "Jump" 和「选择A」被拒绝。
- 通用基础学习段带上 intensity light 会被拒绝。

## 决策

[学习系统决策](../feature/2026-10-05-student-learning.zh.md)仍负责课程证据、奖励和复习。本笔记负责时长、反馈对齐、选择题和摸底强度。

`blockMinutes`、`breakMinutes` 和 `dailyMinutes` 仍是家长确认的建议。超过建议、处于 `breakUntil`、或当天已超过建议时，`start`、`task`、`answer`、`hint` 和 `record` 仍然成功。新段的截止取「现在加上 `blockMinutes`」和下一个上海午夜中较早的时刻，不按当天剩余分钟缩短。`stop` 记录实际经过时间，并仍设置 `breakUntil`。在该截止之后保存的作答带 `late: true`。`studyStatus` 返回 `timeNotice` 和 `time`：本段已用、建议时长、今天累计，以及北京时间 `HH:MM` 的休息时钟。工作台保持作答和新的开始可用，并显示同一条建议。

针对当前题目的反馈必须已有保存的回答。`id` 必须相同。`topic` 和 `prompt` 在 NFKC、全半角、首尾空白和连续空白折叠后比较。`response` 可以等于已保存的回答、原始输入、折叠后的文本，或选择题字母。没写的 `mistakeId`、`objectiveId`、`variant` 和 `figure` 从当前题目抄上。写了但不一致时，错误指出字段和期望值。

选择题接受大小写、首尾空格、全半角，以及 A–D 字母编号，包括选A、选择A 和答案是A。保存的 `response` 是公布的选项原文。`rawResponse` 保留去掉首尾空白后的输入。

`intensity` 只在 `diagnose` 模式保存。其他模式忽略它，`study_update` 在返回里加上说明。

## 考虑过的替代方案

**到点仍然拒绝，只把文案说软。** 这次会话要求孩子能继续。只要仍是拒绝，学习就会停住。

**从档案里去掉这三项时长。** 家长仍然要选择一段建议长度。去掉字段会丢掉这个偏好和休息时钟。

**要求反馈把题目每个字段逐字重复一遍。** 这就是答案保存后失败的检查：重写的回答被拒绝，错误也没有说明哪个字段不同。

## 验证

学习测试覆盖超时保存、不被缩短的学习段、点名字段的反馈错误、选择题字母，以及被忽略的强度。工作台测试在超过建议后仍可作答，并在建议休息期间提供「现在开始」。没有在真实 DSH 浏览器里跑过。

## 后果

插件不在建议时刻停止学习段。辅导可以继续，`timeNotice` 是要转述的原文。超时作答仍然可以区分。同一时间仍只能有一段学习，校内同步仍要求已确认课程。反馈如果写了不同的题干或题图，仍然失败，错误会引用期望值。
