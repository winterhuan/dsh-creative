# Agent Note: 按任务划分短剧、游戏与视频技能

Status: implemented

[English](2026-10-01-creative-task-skills.md) | 中文

## 问题

按生产阶段拆分技能，使小范围创作请求加载无关流程并反复交接相邻工作。部分参考强制固定方案数或重复评审，视频配音前检查甚至要求观看尚未生成的最终文件。

## 决策

短剧提供五个任务入口：项目与改编、写作、视觉、生产和审查。四种视觉模式共用一个技能，创作文档及稳定 ID 仍分别保留。收到小说路径不要求全书分析；分析声明覆盖范围，并区分原著证据与改编决定。

游戏提供四个入口：接入与原著分析、设计、构建和 QA。设计合并概念、世界与美术工作。已有选择不触发强制备选方案或固定动作、系统配额。模板只用于适合的 Web 项目；工具缺失不授权改变目标运行时。QA 保持独立，当前认证驱动只验证 Chrome 构建。

视频保留 `video-recap` 和 `video-script`。理解、剪辑、配音与合成是带执行脚本的条件参考，不注册为技能。写稿不启动付费生产。cut 模式的旁白使用真实剪后时间线，成片观看发生在渲染之后。语义评审服从请求范围和运行时实际严格模式，不无条件循环追求 PASS。

所有资源使用 DSH 原生读取。短剧与视频提供包内资源根，游戏资源仍跟随各任务。脚本路径及经检查的分发副本保持稳定，供生产消费者使用。仅含资源的目录不参与技能发现。删除的技能名不保留注册别名。

[四领域拆分决策](../architecture/2026-09-30-creative-four-domain-plugins.zh.md) 继续拥有独立安装和不新增共享运行时包的边界。[短剧成片](../feature/2026-09-27-short-drama-finished-episode.zh.md)、[游戏证据](../feature/2026-09-27-novel-to-game-playability-evidence.zh.md) 和[视频交付](../feature/2026-09-27-video-recap-delivery-and-compliance.zh.md) 决策继续约束授权、来源身份、实际执行证据与草稿限制。[小说精简](2026-09-30-story-skills-native-resources.zh.md) 独立拥有小说流程与 Role 资源。

## 考虑过的替代方案

**将旧名字保留为隐藏技能。** 隐藏入口仍参与模型发现，并保留阶段路由义务。条件参考能够提供工序，不必增加调用身份。

**每个领域合成一个大技能。** 这会加载无关工作，模糊生产授权和审查范围。按任务保留入口，既保留这些边界，也不要求每次走完全部阶段。

**只搬动旧指令。** 这仍保留强制比较、中间审批与重复检查。流程删除这些义务，同时保留已确认设计的变更裁定、付费操作确认和真实交付验证。

**迁移所有运行脚本或抽共享包。** 现有合成与分发消费者已使用稳定路径。技能发现不需要运行时迁移或新依赖。

## 影响

三个领域的目录从 23 个入口缩减到 11 个；视频仍有两个用户可见命令。已删除的旧命令改用所属任务入口。专项工作仍可读取详细参考，独立分发包之间的生产脚本仍需同步。

Provider 检查覆盖目录身份、资源提示与参考可读性。现有离线生产和 QA 测试覆盖保留的执行契约。这些检查不证明艺术质量、在线供应商可用性或发布批准。
