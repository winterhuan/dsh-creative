# Agent Note: 六个小说技能与原生资源

Status: implemented

[English](2026-09-30-story-skills-native-resources.md) | 中文

## Problem

十四个小说入口按篇幅和管道阶段拆开相关创作任务。接入已有文本要求全书分析，润色与检测重叠，重复参考副本携带互相冲突的强制技巧。专用参考工具重复了 DSH 的资源发现和文件读取能力。

## Decision

公开入口是 `story`、`story-write`、`story-analyze`、`story-review`、`story-polish` 和 `story-cover`。长短篇流程作为任务内按需读取的独立参考保留。`story` 负责工程准备、市场研究、作者偏好和已有文本接入；已有工程直接继续，原始文本接入不要求全书分析。浏览器操作改为内部指引。移除的技能名称没有注册别名。

六个技能使用包内 knowledge/story 资源根目录。工作流与受委派的专业 Agent 均使用原生资源提示和 read，任务提供所选 Role 文件与资源根。原生文件权限继续有效；专用参考工具、枚举和遮蔽 guard 保持移除。

本决策部分取代[工作台决策](../feature/2026-09-03-creative-workbench.zh.md#composition-and-knowledge)中的专用读取方式。原记录继续负责 Role 权限、生产和工作台归属。[四领域决策](../architecture/2026-09-30-creative-four-domain-plugins.zh.md)继续约束插件独立打包；story 内部共用资料不构成跨领域运行时依赖。

写作保留细纲就绪、当前字数哈希与原子追踪事务。[原生协作决策](../feature/2026-10-01-creative-role-agents.zh.md) 移除固定评审 JSON 和模型元数据，普通审稿仍按任务范围进行，自审不宣称独立性。短篇局部交付不要求完成整篇。风格配额和检测分数不决定验收，朱雀需明确请求。

## Alternatives considered

**保留十四个入口别名。** 这会留下路由歧义和目录成本，没有增加独立的作者任务。

**合成一个巨型技能。** 简单工作也会加载无关的长篇、短篇和检测流程。六个任务入口保留可发现性，并按需读取细节。

**保留专用参考读取工具。** 它能固定包内来源，但固定 Role 路径也能保留这一性质，原生读取同时提供权限、分段和文件观察。插件专有的路径枚举和 guard 不再有独立职责。

**接入前强制深度分析。** 这能提高全书覆盖度，却让简单整理依赖庞大的拆解管道。接入只读取当前操作需要的内容；正式续写仍要求可核验的当前事实和有效追踪初始化。

## Consequences

目录从十四个入口缩为六个。按相同内容合并删除了 75 份参考副本；聚焦的工作流参考保留长短篇差异。技能和辅助脚本仍在可独立安装的 story 包内。旧技能命令明确移除，用户选择六个当前任务之一。

Provider 测试验证精确目录、原生资源根和资源可读性；Role 测试验证固定参考路径及专用读取器缺席。脚本测试保留哈希失效和追踪检查，并覆盖无付费点的免费短篇。前向验证覆盖局部交付与单会话评审边界。这些检查不能证明真实模型的正文质量或外部检测准确性。

长篇多章提取使用[短章节卡](2026-10-04-story-short-chapter-cards.zh.md)里的短卡片和批次 workflow。本记录仍负责六个入口和原生资源读取，并保持有效。
