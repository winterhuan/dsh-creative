# Agent Note: Antfarm 团队工作流运行时

Status: implemented

[English](2026-11-08-antfarm-team-workflow-runtime.md) | 中文

## 问题

可复用团队需要持久执行、明确验收，以及用户可操作的配置和控件。原版 Antfarm 轮询 worker 与 OpenClaw 配置不能提供原生 DSH 所有权。先前通过的测试不能批准被后续修复改变的候选；中断子会话也不能证明其效果从未发生。

[初期编码运行时决策](2026-11-08-antfarm-reimplementation.zh.md)确立检查点与工作区归属。本决策替代其仅编码、只读界面和仅人工重启范围，保留独立业务日志、原生子会话执行与资源保护。[团队工作流规划](../../proposed/architecture/2026-11-08-antfarm-team-workflow-plan.zh.md)保留本地实现证据尚未满足的外部验收要求。

## 决策

DSH 管理 presets、模型调用、jobs、权限、子进程和 Session 记录。Antfarm 管理可复用工作流、已接受结果、重试、资源与恢复。单一 Host 执行器持久准入工作，并在 owner 之间轮换尝试容量。操作系统持有的 SQLite 锁排除同根目录第二 Host；version 3 JSONL 检查点保持权威，SQLite 查询索引可重建。

原始 owner 恢复不经过模型回合重建原生根会话权限。启动时调度已保存安全工作。未结算尝试保持中断，直到 owner 检查效果并提供核对指导。失败 Run 需要显式追加重试预算。超时或诊断不能将不确定状态转为已接受。

候选标识源码提交及内容。必需检查引用所属 cwd 中、未变化候选上的已捕获成功前台 shell 执行。修复使先前最终检查失效。声明的 GitHub 交付验证候选 PR HEAD 和不同身份的批准审查；前端验收可要求浏览器执行与保留图片。原生工具执行效果，Host 查询验证结果事实。

项目、配置的用户目录与包内工作流形成明确优先级。编辑保存可写副本，校验规范路径和匹配修订，串行化操作并使用唯一临时写入。包内定义保持不可变。运行中工作保留解析后快照；启用状态影响新准入。未保存草稿跨导航保留，过期保存保留草稿供修正。

Git 工作流保留经身份校验的 worktree 与分支。文件工作流快照显式输入，使用独立所属目录并按摘要保留输出。私有成果存储允许工作区清理后下载。原生 Session 面板及授权跨会话看板读取同一运行时投影；控件绑定原始 owner 与预期 Run 修订。

Owner 通知持久保存投递状态并等待原生 Session 刷盘。显式 webhook 使用凭据引用与有界投递；未知结果保持不确定。无模型健康检查诊断不活动或超期工作，仅通过唯一执行器调度安全工作。

## 已考虑的替代方案

**复制 OpenClaw worker 与轮询 cron。** 这会给 DSH 引入第二调度器和模型上下文。原生容量与 owner 恢复通过单一执行归属提供同样的自主推进。

**保持配置和 Runs 只读。** 这排除了所要求的配置管理与操作恢复。修订和路径保护使有界编辑与控件可审阅，无须任意文件系统写权限。

**信任模型报告的测试或 PR 链接。** 声明可能描述旧候选或未完成效果。捕获命令与远程事实查询将验收绑定到当前输出。

**自动重跑所有中断工作。** 子会话可能在检查点提交前已执行效果。本地日志或全新子会话都不能保证外部效果恰好一次，因此仍需核对。

**由单元测试标记全部原版能力已验证。** 原版导入与本地 fixtures 证明实现行为；真实模型、GitHub、浏览器、webhook、平台与安装验收需要各自执行证据。

## 后果

实现覆盖原版团队及其原生操作等价功能，并增加研究/写作、工作流编辑与 Run 控件。原版轮询/进程管理命令拼写变化；导入 expectations 不自动添加原生检查、视觉或交付强制要求。[能力对照](../../../../plugins/dsh-antfarm/PARITY.zh.md)管理这些差异与验证范围。

Run 步骤串行与全新有界尝试仍是明确选择。Worktree 和 presets 不隔离凭据、网络或 shell 效果。原生 Workflow/Agent Team 保持独立，直到提供必需持久游标与验收 binding。[DESIGN](../../../../plugins/dsh-antfarm/DESIGN.zh.md)管理机制，[HANDOFF](../../../../HANDOFF.md)管理当前仓库验收状态。

本次局部笔记审查保留并交叉链接初期运行时笔记，因为其替代方案与工作区理由仍指导修改。两份规划继续保留未满足的外部验收及原生收敛条件；不能仅由源码覆盖认定规划全部交付。
