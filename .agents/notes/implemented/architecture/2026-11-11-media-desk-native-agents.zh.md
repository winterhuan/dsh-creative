# Agent Note: Media Desk 原生创作 Agent

Status: implemented

[English](2026-11-11-media-desk-native-agents.md) | 中文

## Problem

仅有文字请求的工作台无法复用原生技能、研究、批准与持续对话。在 Wiki 输出旁保留私有可编辑副本，也会让外部改稿依赖同步。创作执行、可编辑内容与成稿接受需要不同的归属，同时保留既有作品、来源、偏好、媒体和指标。

## Decision

DSH 为每篇作品管理持续的普通 Session，并为全局助手管理独立 Session。Media Desk 保存其实际身份、DSH home 和 Wiki 工作区，重启后保留这些关联。专用创作 preset 提供文件、搜索、Shell、技能、问答、批准和压缩能力，并带有创作 persona；不包含编码、插件管理、定时、目标和自动委派。缺少服务、preset 或已保存 Wiki 时禁止执行，不回退为直接模型请求。

有效的 `llm-wiki` 技能和 Wiki 指令管理研究与知识维护。主题综合提供事实；明确选中的作者样文提供个人文风。已接受生成材料自动保存到 Notes。高价值新知识遵循 Wiki 维护流程；创作输出不会仅因保存位置而成为权威知识。明确的只读请求禁止业务写入。

Notes 为每篇作品和语言保存一份当前 Markdown，并分别保存收藏来源材料、自定义偏好与已接受媒体。直接位于 `notes/` 下的内容类型目录便于其他创作工具复用。Media Desk 保留稳定身份、引用、原始指标、结构化策划、运行状态和回执。固定 AI 原稿、非当前草稿与恢复版本保留为历史。[原生接受决策](2026-11-12-media-desk-native-acceptance.zh.md)管理文件发布、版本校验、候选接受与恢复。

四个有界业务工具分别读取已登记对象、应用普通编辑、受理成稿或重画，以及提交结构化候选。实际 Session 与输入关联授权这些操作。先接受策划，再生成依赖它的文字与媒体；每次成稿冻结相关偏好和输入引用。普通助手文字不能替代持久接受结果。

原生 Stop 结束当前轮次并保留无关队列输入。取消成稿使所属文字与媒体尝试失效。开始新对话等待所属工作停稳，保留旧 Session 及其待发输入，再绑定新 Session，不唤醒旧收件箱。原生模型选择控制下一尚未准备的步骤；图片配置保持独立。Client 使用官方对话工厂和 Media Desk Session 作用域，保留工作台内容动作及普通 Session 导航。

HTTP 与受支持订阅生图后端保留各自的尝试、结果目录和取消约定。订阅工具不增加自动重试或 HTTP 回退。导出从已接受文字、来源与媒体生成新快照目录。排期与平台发布仍是分别执行的手动操作。

后续 Monid 账号采集、刷新、连接与费用界面不再提供。历史账号、导入内容、来源链接和指标继续支持手动与 CSV 复盘。链接收藏与明确选中的网页样文仍可使用。写作规则提案需要审查与启用；导出语气指令从当前启用偏好派生，不能重新施加停用规则。

## Alternatives considered

**在提示词构造器中直接读取 Wiki 文件。** 选择少量文件的改动更小，但会重复技能发现与检索，同时缺少原生执行、批准和可复用技能。

**使用独立创作工作区与手动导出。** 这能分开创作与 Wiki 目录，但增加工作区选择和保存步骤。选定的 Wiki 工作区应用自身指令并自动保存已接受创作材料，业务状态仍由 Media Desk 管理。

**Media Desk 保存正文，Notes 保存副本。** 首批改动更少，但保留重复的可编辑文字，Obsidian 改稿需要同步后才能进入工作台。共用主存文件需要额外的版本与恢复工作。

**按插件名称集中保存材料。** `media-desk/` 包装目录让路径绑定一个应用，并增加导航层级。内容类型目录便于复用；已登记关联仍决定 Media Desk 可以修改哪些文件。

**仅把 `callModel()` 替换成 Agent 包装器。** 一个最终文字块、全局模型状态、浏览器负责成稿和仅在内存中的任务，无法证明原生完成，也不能保证取消后安全写入。

**每次小型生成都创建新 Agent。** 这能隔离结构化阶段，但会丢失选定的持续对话，并重复加载技能与上下文。因此制作尝试与持续 Session 使用不同身份。

**把全部内容和编排放入聊天历史。** Session 证据不能替代可编辑作品、排期、稳定媒体身份或版本校验。Notes 保存持久内容，Media Desk 记录业务接受。

**复制 Antfarm 调度器或为面板虚构父 Agent。** DSH 已有原生根 Agent。Antfarm 的 SQL 工作流和全新尝试身份解决的是另一个问题；本集成使用 DSH 公共约定，不采用其他插件的业务引擎。

## Consequences

原生执行保留普通工具、输入与历史，共用 Notes 文件支持工作台和外部编辑器。技能与研究会增加上下文和延迟。当前启用偏好优先于导出指令，原始样文与主题证据保持可区分。

版本化迁移通过已验证备份保留历史身份和语言版本。旧聊天作为历史上下文保留，不伪造原生工具事件。恢复不会自动重复效果不确定的模型、生图或 Wiki 写入；回滚保留较新的 Session 与 Notes 证据。协作所有权覆盖同机本地 Host，不覆盖非协作编辑器、网络共享目录或断电持久性。

确定性 Host 与 Session 检查覆盖接受和恢复，隔离真实模型运行证明实际技能加载、来源读取及已接受文字保存。这些检查不认证写作质量或事实。[包说明](../../../../plugins/dsh-media-desk/README.zh.md)和发布证据明确保留付费生图、真实订阅账号与未测平台的验证限制。CSV 复盘追加平台汇总；重复累计快照可能重复计数，不能替代逐帖实时指标。
