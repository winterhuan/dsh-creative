# Agent Note: Media Desk 原生结果接受

Status: implemented

[English](2026-11-12-media-desk-native-acceptance.md) | 中文

## Problem

助手可能在原生轮次失败或被停止前提交看似有效的候选；文件也可能先于元数据回执发布。将助手文字、idle 状态或 Markdown 副本视为已接受作品，会让不确定结果覆盖后续编辑，并在崩溃后重放外部效果。

## Decision

DSH 管理作品／全局 Session 及其原生输入、工具、批准和问答历史；Media Desk 管理业务受理与接受。结构化策划、脚本、风格与规则候选须满足实际关联 Agent、匹配的已消费输入、持久成功的轮次结束、原 Notes 版本和持久接受回执。候选保持私有，不选择当前正文。普通业务编辑返回自身即时校验的回执。

Notes 保存唯一可编辑的作品、材料与偏好文字，以及每个媒体身份的单份已接受文件。固定 AI 原稿、偏好版本、原始选题与恢复快照属于历史记录。Store 保留引用、语言选择、结构化策划、运行状态和原始指标。稳定媒体身份在重画后仍可读取；导出使用新目录及正文／媒体清单。

每次成稿受理冻结所选写作偏好和材料／语言版本。已接受策划启动依赖它的脚本与独立媒体尝试。当前正文编辑不作废兄弟图片；旧策划不能接受新脚本，新策划也不能将旧脚本与新媒体混合导出。当前原生模型选择作用于下一尚未准备的步骤，不为整次制作冻结同一文字模型。

原生 Stop 取消当前轮次并保留待发输入；整次成稿取消使其文字与媒体尝试失效。开始新对话先等待活跃的所属工作停稳，保留旧 Session 与收件箱，再关联新 Session。队列编辑和引导保留原生消息身份，同时使变化的业务阶段输入失效。

同机写入所有权覆盖规范化的数据目录及每个保留的 Notes 根目录。非协作编辑器在文件发布及回执接受时通过字节检查；被移开的字节和独立候选支持冲突核对。恢复核验持久文件、输入与回执，复用已知候选，不自动重复不确定的模型、生图或 Wiki 写入。离线回滚恢复已验证的迁移前备份，同时保留后续 Notes 和 Session 证据。

[原生创作决策](2026-11-11-media-desk-native-agents.zh.md)管理创作组合、Wiki 存储与采集选择。本记录管理接受与恢复；[包说明](../../../../plugins/dsh-media-desk/README.zh.md)管理当前行为和验收限制。

## Alternatives considered

**以助手文字或 idle 判定成功。**两者都不能证明匹配输入已成功完成，或文件与回执已接受。原生持久事件与显式候选工具保留该区别。

**私有可编辑文字加 Wiki 副本。**两份当前正文需要同步，可能覆盖外部编辑器。Notes 管理可编辑内容；私有历史候选支持恢复，不形成第二份当前正文。

**重启后重放整次制作。**缺少回执不能证明模型、生图或知识写入尚未发生。显式重试保存复用保留字节；不确定外部效果须由用户重新操作。

**统一取消范围或冻结文字模型。**原生纠正与继续对话需要轮次级控制；成稿管理更大范围的图片尝试。实际文字模型由原生步骤准备管理，不由插件默认值管理。

## Consequences

该设计保留既有作品，提供共享 Markdown 主存、持久回执和可恢复候选字节。文件发布与 Store 替换仍是带日志的独立操作；本地协作锁不能使普通编辑器成为原子事务参与者。不支持跨机器共享目录、断电持久性或外部效果仅计费一次的保证。

真实模型与确定性原生运行证据证明执行和已接受存储，不证明事实或写作质量。付费生图与订阅账号可用性取决于所选外部服务。本机发布记录明确验收范围，不将受控 fixture 作为真实服务证据。
