# Agent Note: Writer 浏览任务使用 Box 与 Ego

Status: implemented

[English](2026-11-07-writer-box-ego.md) | 中文

## 问题

Writer 需要浏览器登录态、页面 JavaScript 和可恢复的扫榜。复制个人 Profile、关闭无关进程的本机 Chrome 启动器会打断作者操作。仅限 Ego 的前置条件使作者无法选择云端浏览器。

## 决策

[浏览器技能](../../../../plugins/dsh-writer/packages/winterhuan/writer/skills/browser-cdp/SKILL.md)默认使用 Box，显式选择时使用 Ego。保留既有名称以稳定项目技能发现。七个采集器与研究员模板共用选择规则。浏览器失败不静默切换后端；既有无需浏览器的 HTTP 路径仍可用。

采集器留在本地项目。Box 操作通过官方 CLI 的远程终端和 Box 内的厂商 Chrome 启动器完成；Ego 操作通过官方 Ego CLI 与 TaskSpace API 完成。报告与检查点因此保持在一起，无需同步项目或复制登录 Profile。Box CLI 登录独立于宿主的 MCP 连接。厂商技能与实际工具定义负责通用浏览器操作说明。

每个 Box 任务创建自己的页面，在 Box 用户状态目录记录浏览器身份、目标页与所有权。文件系统锁将操作串行化，浏览器动作之前先持久化意图。交接与不确定状态在本地进程退出后仍保留。续接不能替换已关闭的目标页或已重启的浏览器。显式恢复刷新任务页面并丢弃其 JavaScript 上下文，但不证明服务端请求已取消。Ego 保留自己的交接与安全超时规则。

逐次调用标记与完整 JSON 结果将 Box 回应绑定到本地调用。大结果暂存在 Box，分段传回并核对大小与 SHA-256 后删除，避免实测中单次大回应引起的远程终端流重置。采集检查点绑定浏览器、Box、参数与解析器版本；检查点不证明浏览器操作已停止。登录凭据留在页面上下文中，错误消息不包含页面异常正文。成功清理只关闭任务创建的页面；异常与交接保留现场。

[写作预设](../feature/2026-10-31-writer-preset.zh.md)继续负责 bundled/workspace 挂载与项目自定义副本保护。已有工作区副本需要授权后成套刷新；源码修改不会更新日常远程安装。

## 考虑过的替代方案

**仅用 Ego：** 它提供原生 TaskSpace 所有权，但用户要求默认 Box、可选 Ego。之前的独占后端提案已过时；其中长期有效的所有权与凭据约束保留在本决策和实现中。

**本机 Chrome 与重复 CDP 辅助模块：** 它们在所选后端之外引入 Profile 复制和进程生命周期责任。独立启动器与两份未使用的辅助模块已移除。

**所有采集调用都走 Box 浏览器 MCP：** 已文档化操作未提供采集器所需的页面执行接口。通过官方远程终端运行小型浏览器 worker，可保留既有解析器和本地检查点，无需依赖未文档化的 MCP 方法或通用驱动注册机制。

## 影响

Box 增加网络延迟和单独的 CLI 登录。Box 与 Ego 分别保存网站登录态。直接调用 Box CDP 不提供 Ego 的自动用户接管停止信号：人工操作前必须暂停采集，调用者不能并发操作同一页面。远程进程被终止可能留下锁；调用者必须检查进程和页面，不能自动删锁。结果不明的页面创建失败可能需要手动清理任务窗口。

Box 路径已在 macOS 到 Linux、Node 24 与 Chrome 157 环境验证：DOM 执行、1 MiB 结果完整分段传输、恢复与同页续接、刺猬猫九榜各十条及完整作品链接、黑岩官网公开书库两页 200 本及公开作品元数据。显式选择 Ego 的真实页面探测通过。单元测试覆盖选择、所有权、失效会话、检查点与失败结果传输。黑岩使用 `https://www.heiyan.com/all.html`，无需管理后台账号；混合长短篇的书库及累计点击不代表短篇热度。其余平台全流程、Windows 启动行为、Box 自动感知人工接管尚未验证；共享适配器测试不代表这些场景通过。
