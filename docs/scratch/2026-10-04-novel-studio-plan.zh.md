# 小说工作台：按现有插件设计

[English](2026-10-04-novel-studio-plan.md) | 中文

## 摘要

工作台继续用 `@winterhuan/dsh-story`。目录、写入钩子和章节事务保持现状。这次只改三处：长篇直接读共享拆文库，写正文前把已经要读的文件展示给作者，朱雀密钥从共用创意生产设置拆到小说自己的设置页。

## 相对现有代码要改的

长篇引用拆文时，`设定/题材定位.md` 只登记 `拆文库/{书名}/`，写作直接读那份共享分析。已有的 `对标/` 目录仍可被工作台打开。新的引用不再复制进去。本书自己的拆解不能登记成自己的对标。

准备阶段先列出 `追踪/上下文.md`、本次读到的角色状态、伏笔、时间线、细纲、上一章和拆文页，并带上 `tracking_commit.py check` 返回的修订号。作者看到这份清单后才写 `正文/`。清单不另存成文件，也不替代 JSON。

朱雀密钥只留在 story 插件的 `story` 设置命名空间。`story_zhuque` 读取该命名空间，默认凭据引用仍是 `MAKERS_API_KEY`，密钥仍进凭据库。短剧、解说和聚合包继续用 `creative-produce` 的六个提供方。聚合包里的 `creative_produce_run` 不再携带 `story-zhuque`。

## 保持不变的边界

长篇目录是 `正文`、`大纲`、`设定`、`追踪`、`对标`、`参考资料`。短篇文件是 `正文.md`、`设定.md`、`小节大纲.md`。`拆文库` 在工作区上，供多本书使用。`长篇/` 和 `短篇/` 只是书的容器。工作台只列出这些目录和短篇文件。

长篇已有 `追踪/_tracking-state.json` 时，没有对应细纲的正文写入会被拒绝。正文写入成功后，由指定提交者经过检查和审稿，用章节事务更新这份 JSON。写手不改追踪。派生视图由事务生成。短篇 `正文.md` 不走这道检查。

章节事务使用哈希和 `expected_state_revision`。作者记忆在工作区 `.story/作者记忆/`，只记写法偏好。会话里的未保存编辑是工作台缓冲，不是书的目录。

## 一本书

```text
工作区/
├── .story/作者记忆/
├── 拆文库/{书名}/
└── {长篇书名}/
    ├── 正文/第NNN章_章名.md
    ├── 大纲/大纲.md
    ├── 大纲/卷纲_第X卷.md
    ├── 大纲/细纲_第NNN章.md
    ├── 设定/
    ├── 追踪/_tracking-state.json
    ├── 追踪/上下文.md
    ├── 追踪/角色状态/{角色名}.md
    ├── 追踪/伏笔.md
    ├── 追踪/时间线/作者真相.md
    ├── 追踪/时间线/读者已知.md
    ├── 追踪/逐章记录/第NNN章.md
    ├── 对标/{书名}/
    └── 参考资料/
```

`设定/` 是作者确认的人设、世界观和文风。`大纲/` 是还没发生的计划。`正文/` 是已写入的故事。`追踪/_tracking-state.json` 是已提交章节的事实；旁边的 Markdown 由 `tracking_commit.py` 生成，程序不反向解析。作者真相和读者已知是时间线的两个派生视图。

短篇是同级的 `设定.md`、`小节大纲.md`、`正文.md`，不建 `追踪/`。技能里的 `草稿/` 只放探索性正文，不推进追踪。未保存修改留在当前 Session 的编辑缓冲里。

## 阅读现有文件

已有 Markdown 就是可阅读的层：`设定/`、`大纲/`、`追踪/` 的派生页、`拆文库/`。查询先读 `追踪/上下文.md`，再按需要读一个角色状态、一条伏笔、作者真相或读者已知、本章细纲和上一章正文。完整 `_tracking-state.json` 不进入正文提示。

收录就是现有的 `chapter commit`。事务成功后派生页一起更新。体检沿用 `tracking_commit.py check`：派生页必须与 JSON 逐字一致。对标材料按题材定位直接读 `拆文库/{书名}/` 里本步需要的页。不新增 `index.md` 或 `log.md`。

## 一次写作

长篇仍走准备、写作、`chapter check`、审稿、最多两轮修订、`chapter commit`。连续章由父会话串行调用，上一章提交验证后再开始下一章。短篇仍走短篇写作流程。设计字段通过前不写正文。

讨论不改追踪。审稿不改文。探索性文字可以进技能约定的 `草稿/`。正式正文写入 `正文/` 后，仍要经过钩子要求的复核和章节事务。

## 工作台

工作台继续显示上述目录里的文件，用 Session 缓冲和文件版本保存。外部修改保留尚未保存的编辑内容。不增加任务抽屉或第二套事实。

## 开发笔记

本文是规划。目录、钩子和章节事务以当前代码为准。拆文读取、写前清单和朱雀设置拆分已经写进技能说明和设置代码。设置页还没有在真实 dsh 里点过。验证后若行为有变，再写入 story README 和 `.agents/notes/`。
