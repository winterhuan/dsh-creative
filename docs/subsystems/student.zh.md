# 学生学习

[English](student.md) | 中文

## 概述

引导短时学习，并跨对话保留课程身份、学生作答与复习进度。家长确认课程，学生在同一组建议时长内练习或探究问题。本页定义职责与信任边界，包 README 负责使用与配置说明。

<a id="ownership"></a>
## 职责归属

`student` Agent preset 通过作用域内的 `/agent` 入口拥有模型能力。Host 路由和设置保持全局注册。侧栏入口跟随所选会话的投影；隐藏工作台保留原有存储。模式选择不迁移历史，也不授予文件系统权限。

独立安装的[学生插件](../../packages/education/student/README.zh.md)拥有技能、参考、学习工具、交互侧栏与工作区状态。包位于 `packages/education`，不依赖创作插件。DSH 负责对话、模型、图片附件、工具历史和文件系统授权。插件不下载教材，也不提供独立辅导运行时。

<a id="evidence"></a>
## 资料与学习证据

一个工作区对应一名学生的一学期。资料记录包含地区、年级、学期、学年、学制、科目与版次依据。已确认校内课程必须匹配学生档案，并保留真实家长陈述。教材未知时允许基础练习，不能声称校内同步。课程变化时资料保留各自身份，使历史作答仍可追溯。

二年级上册未提供某科教材时，技能使用随包提供的语文或数学课页；用户资料优先。默认教材只提供学习内容，不建立校内课程或家长确认。版本和读取方法由[包说明](../../packages/education/student/README.zh.md#use-default-textbooks)维护。

图片转录依赖模型。用户确认题干且辅导者记录答案依据之前，新错题保持待核对；存在疑点的图片不会自动进入复习。提示后答对和独立答对分开记录。来源分类和保存的确认是证据记录，不是对真实性或正确性的保证。模型输入仍受已配置提供方的数据处理规则约束。

一、二年级随包提供语文、数学、英语上下册的知识地图：单元、知识点、学习目标和同科关系在加载时校验，供宿主、工具和工作台使用，状态只保存目标引用。内置目标视为已核对，不经家长确认即可用于出题、作答、错题归类和练习单；地图之外的概念仍需家长确认。掌握状态、薄弱点和每日建议由作答、纸上结果和错题复习阶段按同一套固定规则推导（跨年级摸底同样适用），描述证据而不判定能力；地图依据课程标准与通行教学顺序，不代替学校课本。摸底学习段按科目定期取样未探查、久未练习和超期已掌握的目标，作答强制关联目标，结果直接进入掌握状态；选项题把作答归一到已发布的选项，并接受大小写、全半角和字母编号；其他年级学期的地图只能浏览，其目标不能用于出题。

概念按科目保存定义、例子和资料依据，经过用户核对后才可用于学习目标；目标限定科目方法。前置、组成、对比、解释和因果关系连接同科已确认概念，其中因果方向及依据必须明确。错题关联学习目标，旧记录保留原主题并等待人工归类。练习单冻结错题来源、题目、答案依据与目标；学生版卷面只包含题目。巩固题按换数字、换情境、说理的阶梯升级并保留原错因；内置目标带出题要素（错因、出题要点、变式维度）与三层提示阶梯。纸上作答先存为转录草稿，家长在工作台核对确认后才进入独立结果记录。这条路径不代替当前交互题目的作答。

存储层使用当前会话的文件系统与沙箱策略，校验持久化数据，写入前比较已观察的文件版本，读取按文件版本缓存已校验状态，任何写入或外部变更使其失效。冲突或无效状态会停止修改。侧栏 HTTP 接口仅解析主会话，接受本机同一来源请求，每次修改必须携带修订号；轮询可携带修订号，证据未变化时只返回时间状态。UI 不能提交评分或星星。题目、原始回答和提示请求共同持久化，原生对话负责教学与图片。状态查询保留不存在的状态，并分页返回历史；奖励和复习间隔不只保存在聊天记忆中。

工作台把练习单渲染为网页预览，家长经浏览器打印对话框打印或另存为 PDF；Host 不生成 PDF，也不调用系统打印队列。可选的 DSH SenseVoice Bundle 将转写文字插入原生对话草稿，学生核对后发送，学习工具才保存作答；插件不从文本推断发音质量。

<a id="time"></a>
## 时长与奖励

学习段、休息和每日时长是覆盖三科与探究的建议。经过时长包含等待，并不测量注意力。超过建议时长、休息未结束或当天已超过建议时，开始、作答和反馈仍然保存；超过建议截止的作答标为 late。新段按单段建议时长计，不按当天剩余分钟缩短，建议截止不跨过上海午夜。侧栏保持作答可用，并显示同一条建议；技能转述 timeNotice，也可以建议离屏休息。插件无法锁定任意聊天或屏幕。取舍见[软提醒决策](../../.agents/notes/implemented/bug-fix/2026-10-18-student-soft-time.zh.md)。

星星依据已记录的参与和复述发放，每日设上限。重复请求不能额外发星，提前停止不受惩罚。间隔复习依据不同日期的独立作答，进度报告描述观察证据，不给出永久能力标签。

纸上作答不要求活动学习段，也不因上传记录而发星。结果保存时间作为可观察的复习日期；独立答对在任何一天都推进复习间隔，提前于到期日的纸上练习也算；答错或依赖帮助只把下次复习日改回第二天，阶段不倒退。
