# 学生学习

[English](student.md) | 中文

## 概述

继续学生的当前题目，保留原始回答，并用已核验的证据安排针对性练习和复习。家长确认学习范围，学生跨学期保留身份。工作台在原生 DSH 辅导旁提供「学习」与「家长」入口。本页定义职责与信任边界，包 README 负责使用与配置说明。

<a id="ownership"></a>
## 职责归属

`student` Agent preset 将教学工具与 skill（技能）限定在 Student 对话内。全局 Host 服务独立读取和核验文件、管理受保护的连接，并支持家长的明确编辑。左侧栏工作台在学生工作区内选择未归档的 Student 主会话，挂载期间持有其原生对话，切换或关闭时释放引用。右侧栏入口跟随所选会话的投影。模式选择不迁移历史，也不授予文件系统权限。

独立安装的 [Student 包](../../plugins/dsh-student/packages/winterhuan/student/README.zh.md)划分五部分职责：

| 部分 | 职责 |
| --- | --- |
| 知识库 | 能力、已确认的课程关联及每类题目的一道母题；学生回答单独保存。 |
| Student skill | agent（智能体）选择教学，通过原生工具直接写正式学习文件，校验后确认独立消费。 |
| 只读 CLI | 校验结构、身份、引用和范围；不写入、修复、评分或选择教学。 |
| 个人存储 | 工作区文件中的学期设置、原题实例、回答、评价、复习历史及明确归档引用。 |
| 官方 OpenMAIC | 原生教学工具、可发现的 skill 与课堂；官方服务负责原始提交与评分。 |

配套工作台提供学习与家长入口、草稿、附件、打印及共享当前动作。DSH 负责对话、模型、图片附件、工具历史和文件系统授权。Student 不增加独立辅导运行时或学生数据库。官方 OpenMAIC 组合提供四个工具与四个可发现的 DSH skill，教学方法和编写资源按需加载。直接教学组件无需先生成完整课堂，组件点击不构成学生证据。

<a id="evidence"></a>
## 资料与学习证据

学生跨学期保留稳定身份。学习段、课堂实例、题目与回答分别保留所属身份。家长一次确认学习范围；没有已确认教材时可进行基础学习，校内学习还需遵守已确认的学校进度。内置能力不自动扩大该范围。兼容的旧证据按原学期和回答身份引用，保留复习日期与首次掌握；扩大的数字范围、词汇集或模态需要新证据。原回答不复制到下一学期。

二年级上册未提供某科教材时，skill 使用随包提供的语文或数学课页；用户资料优先。默认教材只提供学习内容，不建立校内课程或家长确认。版本和读取方法由[包说明](../../plugins/dsh-student/packages/winterhuan/student/README.zh.md#use-default-textbooks)维护。

图片转录依赖模型。存在疑点的题干、回答、帮助和日期保持待核对。家长核对的纸上记录保留实际作答日，接收和评分时间不能确定该日期。模型输入仍受已配置提供方的数据处理规则约束。

能力与题目家族将可评价结果同教材单元和具体变式分开。共享证据消费者从原回答与有效评价推导掌握和复习。改判保留回答身份和原官方评分历史。未核验来源、未知日期和帮助不贡献独立作答日。旧目标与习题 ID 保留明确的兼容路径或待核对状态，单元分数不授予其中全部新能力。

受保护的 Host 传输读取已授权的 OpenMAIC 提交、来源快照与评分，并绑定原学生和活动。访问码本身不授予读取提交的权限。Host 负责凭据、浏览器登录和传输元数据；agent 写正式学习事实，只在只读校验与独立消费通过后推进课堂检查点。模型自写的来源标记和哈希不认证证据。原生回答也必须匹配独立捕获的所属身份，旧原生会话的历史需先授权再读取。

工作台与原生辅导使用同一个当前动作。未完成题目或待评价回答优先，其后处理当前证据缺口、有限复习及已确认范围内的新学。只有学生、学期、学习段、目标、范围及当前官方题目绑定均匹配时，就绪课堂才能从该动作打开；本地补题继续在本地作答。生成和未知提交恢复原 job。补缺检验最多增加三道新题，一轮复习最多进入两类母题。已保存的轮次事实在答错、暂停、刷新和重启后保留这些额度；继续加做复习需有明确请求或期间已进行新目标学习。

工作区读取遵循当前会话的文件系统授权，校验文件成员及已观察版本，直接编辑后独立刷新投影。原生 Remote 方法提供这些读取和明确的人工保存。UI 将学生回答送入原生对话，不能提交评分或星星。无效引用以问题保留显示，有引用的课堂不会因课表日志上限而被删除。[包说明](../../plugins/dsh-student/packages/winterhuan/student/README.zh.md)负责文件布局、恢复和来源核验细节。

工作台渲染练习单预览，家长经浏览器打印对话框打印或另存为 PDF。Host 不生成 PDF，也不调用系统打印队列。可选 DSH SenseVoice 将转写插入原生对话草稿，学生核对后发送。文本不能验证发音质量。

<a id="time"></a>
## 已学时长与奖励

没有单段、休息或每日分钟限制。状态安静报告本段与今日已学时长，日历日使用上海时区。结束或切换活动保留待处理回答。插件无法锁定任意聊天或屏幕。

星星依据已记录的参与和复述发放，每日设上限。重复读取、改判、重放和学期变化不重复发放奖励。间隔复习依据不同实际日期的独立作答，曲线为 1 / 7 / 16 / 35 天。完成复习要求到期后独立答对，未知日期或帮助不能推进。进度描述观察证据，不给出永久能力标签。
