# 学生学习

[English](student.md) | 中文

## 概述

引导短时学习，并跨对话保留课程身份、学生作答与复习进度。家长确认课程，学生在同一每日时长预算内练习或探究问题。本页定义职责与信任边界，包 README 负责使用与配置说明。

<a id="ownership"></a>
## 职责归属

`student` Agent preset 通过作用域内的 `/agent` 入口拥有模型能力。Host 路由和设置保持全局注册。侧栏入口跟随所选会话的投影；隐藏工作台保留原有存储。模式选择不迁移历史，也不授予文件系统权限。

独立安装的[学生插件](../../packages/education/student/README.zh.md)拥有技能、参考、学习工具、交互侧栏与工作区状态。包位于 `packages/education`，不依赖创作插件。DSH 负责对话、模型、图片附件、工具历史和文件系统授权。插件不下载教材，也不提供独立辅导运行时。

<a id="evidence"></a>
## 资料与学习证据

一个工作区对应一名学生的一学期。资料记录包含地区、年级、学期、学年、学制、科目与版次依据。已确认校内课程必须匹配学生档案，并保留真实家长陈述。教材未知时允许基础练习，不能声称校内同步。课程变化时资料保留各自身份，使历史作答仍可追溯。

二年级上册未提供某科教材时，技能使用随包提供的语文或数学课页；用户资料优先。默认教材只提供学习内容，不建立校内课程或家长确认。版本和读取方法由[包说明](../../packages/education/student/README.zh.md#use-default-textbooks)维护。

图片转录依赖模型。用户确认题干且辅导者记录答案依据之前，新错题保持待核对；存在疑点的图片不会自动进入复习。提示后答对和独立答对分开记录。来源分类和保存的确认是证据记录，不是对真实性或正确性的保证。模型输入仍受已配置提供方的数据处理规则约束。

存储层使用当前会话的文件系统与沙箱策略，校验持久化数据，写入前比较已观察的文件版本。冲突或无效状态会停止修改。侧栏 HTTP 接口仅解析主会话，接受本机同一来源请求，每次修改必须携带修订号。UI 不能提交评分或星星。题目、原始回答和提示请求共同持久化，原生对话负责教学与图片。状态查询保留不存在的状态，并分页返回历史；奖励和复习间隔不只保存在聊天记忆中。

<a id="time"></a>
## 时长与奖励

学习段、休息和每日上限覆盖三科与探究。经过时长包含等待，并不测量注意力。状态机拒绝休息期间开始和截止后提交作答。侧栏到时禁用作答并提供明确的停止按钮，技能也负责在对话中停止并建议离屏休息，插件无法锁定任意聊天或屏幕。

星星依据已记录的参与和复述发放，每日设上限。重复请求不能额外发星，提前停止不受惩罚。间隔复习依据不同日期的独立作答，进度报告描述观察证据，不给出永久能力标签。
