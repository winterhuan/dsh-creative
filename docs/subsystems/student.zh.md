# 学生学习

[English](student.md) | 中文

## 概述

引导短时学习，并跨对话保留课程身份、学生作答与复习进度。家长确认课程；没有单段、休息或每日时长限制。学生可按自己的节奏练习或探究问题。本页定义职责与信任边界，包 README 负责使用与配置说明。

<a id="ownership"></a>
## 职责归属

`student` Agent preset 通过作用域内的 `/agent` 入口拥有模型能力。Host 查询服务和设置保持全局注册。侧栏入口跟随所选会话的投影；隐藏工作台保留原有存储。模式选择不迁移历史，也不授予文件系统权限。

独立安装的[学生插件](../../plugins/dsh-student/packages/winterhuan/student/README.zh.md)拥有技能、参考、学习工具、交互侧栏与工作区状态。包位于 `packages/winterhuan`，不依赖创作插件。DSH 负责对话、模型、图片附件、工具历史和文件系统授权。插件不下载教材，也不提供独立辅导运行时。

当前原生对话是默认业务入口。快捷键提交意图；agent 编写正式文件并运行只读验证，应用独立读取有效事实。明确手动表单是补充受保护保存。DSH Session、学习块和学期身份分开；[原生学习架构](../../.agents/notes/implemented/architecture/2026-11-12-student-learning-flow-architecture.zh.md)拥有恢复与证据来源。

<a id="evidence"></a>
## 资料与学习证据

家长兴趣标签写在学习档案上。出题和 OpenMAIC 的 requirement 用它们换场景，可考事实仍在知识地图。每日建议先教需要教学的目标，再练薄弱点，再做到期摸底，再学新目标；到期错题最多列出 2 条，放在这个目标旁边。一个工作区对应一名学生的一学期。资料记录包含地区、年级、学期、学年、学制、科目与版次依据。已确认校内课程必须匹配学生档案，并保留真实家长陈述。教材未知时允许基础练习，不能声称校内同步。课程变化时资料保留各自身份，使历史作答仍可追溯。

二年级上册未提供某科教材时，技能使用随包提供的语文或数学课页；用户资料优先。默认教材只提供学习内容，不建立校内课程或家长确认。版本和读取方法由[包说明](../../plugins/dsh-student/packages/winterhuan/student/README.zh.md#use-default-textbooks)维护。

图片转录依赖模型。用户确认题干且辅导者记录答案依据之前，新错题保持待核对；存在疑点的图片不会自动进入复习。提示后答对和独立答对分开记录。来源分类和保存的确认是证据记录，不是对真实性或正确性的保证。模型输入仍受已配置提供方的数据处理规则约束。

一、二年级随包提供语文、数学、英语上下册的知识地图：单元、知识点、学习目标和同科关系在加载时校验，供宿主、工具和工作台使用，状态只保存目标引用。另有按目标校验的习题知识库，为摸底、示范、实操、变式与每日小卷提供母题、可选配图与微步骤；工作区真题可一并沉淀。内置目标视为已核对，不经家长确认即可用于出题、作答、错题归类和练习单；地图之外的概念仍需家长确认。掌握状态、薄弱点和每日建议由作答、纸上结果和错题复习阶段按同一套固定规则推导（跨年级摸底同样适用），需要教学时沿前置关系先补最近的未掌握目标，反复答错会拉长复习间隔，描述证据而不判定能力；地图依据课程标准与通行教学顺序，不代替学校课本。摸底学习段按科目定期取样未探查、久未练习和超过 35 天已掌握的目标，作答强制关联目标，结果直接进入掌握状态；选项题把作答归一到已发布的选项，并接受大小写、全半角和字母编号；浏览其他册不授予学习范围，已保存的明确匹配跨册范围可以允许其目标。

概念按科目保存定义、例子和资料依据，经过用户核对后才可用于学习目标；目标限定科目方法。前置、组成、对比、解释和因果关系连接同科已确认概念，其中因果方向及依据必须明确。错题关联学习目标，旧记录保留原主题并等待人工归类。练习单冻结错题来源、题目、答案依据与目标；学生版卷面只包含题目。巩固题按换数字、换情境、说理的阶梯升级并保留原错因；内置目标带出题要素（错因、出题要点、变式维度）与三层提示阶梯。纸上作答先存为带置信度的转录草稿，只有明确家长确认后才进入独立结果记录；批量要求高置信、答对、帮助已知且无疑点，其他条目需逐项核对。这条路径不代替当前交互题目的作答。

正式实体文件保存一学期的设置、学习段、练习单与集合。应用读取使用当前会话的文件系统与沙箱策略，校验文件身份和引用，只有真实文件版本与目录成员保持稳定时才复用解析值。共享证据索引推导掌握、复习与小结；跨越时间阈值时无需新写入即可刷新这些投影。原始作答、帮助与评分保留各自身份。无关的有效文件仍可读取，并显式标为部分结果；证据不完整时不能提供当前小结。文件布局、容量限制、带版本保护的手动保存与原字节校验恢复描述由包内[正式文件 API](../../plugins/dsh-student/packages/winterhuan/student/src/files/index.ts)维护。

类型化 Student Remote 通过原生 Gateway 权限接受已注册的 DSH 主会话，提供查询、带编辑字段基线的辅助手动保存，以及分别核对消息接收、回答已保存和有效评分已保存的检查。缺失、已释放与子 Agent 请求会被拒绝，且不会触发激活。资源提供器跟随当前文件和原生重连，读取失败时把保留值标为过期。原生与 shell 写入不受应用版本保护；已观察的有效备份只能覆盖保留版本。迁移与归档逐文件发布，并显式报告部分结果。

辅导者的 shell 负责 `.study/openmaic-lessons.json`、服务生成、轮询与 cookie，完整文件校验后才截取有界课表展示。Host 与浏览器代码不发送该服务的 cookie，也不运行课程。DSH 负责原生教学消息、附件与草稿。插件界面读取独立校验的事实；查询保留不存在的状态并分页返回历史，奖励和复习间隔跨聊天记忆保留。

工作台把练习单渲染为网页预览，家长经浏览器打印对话框打印或另存为 PDF；Host 不生成 PDF，也不调用系统打印队列。可选的 DSH SenseVoice Bundle 将转写文字插入原生对话草稿，学生核对后发送，agent 才保存原始作答；插件不从文本推断发音质量。

<a id="time"></a>
## 已学时长与奖励

没有单段、休息或每日分钟限制。状态安静报告本段与今日已学时长；日历日使用上海时区。agent 明确结束或切换学习块并保留待办；验证拒绝多个未结束学习块。插件无法锁定任意聊天或屏幕。取消时长见[全面改造决策](../../.agents/notes/implemented/feature/2026-10-30-student-overhaul.zh.md)；作答匹配、选项归一与摸底强度仍见[软提醒决策](../../.agents/notes/implemented/bug-fix/2026-10-18-student-soft-time.zh.md)。

星星依据已记录的参与和复述发放，每日设上限。重复请求不能额外发星，提前停止不受惩罚。间隔复习依据不同日期的独立作答，曲线为 1 / 7 / 16 / 35 天；进度报告描述观察证据，不给出永久能力标签。

纸上作答不要求活动学习段，也不因上传记录而发星。家长确认的作答日期保留日精度，并允许逐题覆盖；未知日期保持可见，不进入按日期统计的指标。接收与评分时间不能补成作答日期。当前聊天日期必须匹配当前已授权会话实际消费的输入版本；旧会话保存的声明保持原样，但在当前范围内仍待核验。已知独立答对可以在到期前推进复习；帮助与不确定性不能确立独立作答。
