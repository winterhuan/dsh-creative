# 分类标签

[English](triage-labels.md) | 中文

## 摘要

工程技能将 issue 分配到分类角色时，使用下表映射。这些状态标签与 `bug`、`enhancement` 等主题标签并存。

## 标签映射

| 标准角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交由无人值守的 agent（智能体）执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

技能提到标准角色时，使用对应的 GitHub 标签。仓库采用其他名称时，修改 GitHub 标签列并保留角色含义。
