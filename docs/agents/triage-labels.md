# Triage labels

English | [中文](triage-labels.zh.md)

## Summary

Use the following mapping when an engineering skill assigns an issue to a triage role. These state labels coexist with topic labels such as `bug` and `enhancement`.

## Label mapping

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting for information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an unattended agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

Apply the corresponding GitHub label when a skill names a canonical role. Edit the GitHub-label column if the repository adopts different names; preserve the role meanings.
